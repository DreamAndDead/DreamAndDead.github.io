# idea

纯粹的消消乐改变为单词连线消消乐：每一个方块里面是一个字母，连线之后，如果是一个单词，就将其消除。
在这个基础上的变化决定：
1. 每次消除的顺序必须成为一个句子。
2. 单词之间可能有歧义（比如说某些单词是某些单词的前缀），这样也是可以的，会增加谜题的难度。
3. 再者，引入变化。
4. 引入共同部分的交叉，比如说某些单词之中都有 A，横竖交叉起来可以复用 A 这个字符。




![[Pasted image 20260820225705.png]]

将已有的解谜元素从方形变成六边形，就可以增加一个维度的趣味。

比如对于推箱子或者即时战略来说，从方形变成六边形可以增加更多的计算趣味。

但缺点是，人脑天生对正方形有更好的直觉判断力，对于这种六边形弯弯绕绕的感觉不是那么直观。可能题目非常简单，但是没有这种直观的连线印象，导致卡住，不能更好地理解作者的设计意图。




2D动作游戏像《只狼》那样的核心机制引入的刺激与快感。
