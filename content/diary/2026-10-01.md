## displacement mapping 

![[Pasted image 20261001103726.png]]

Bump 慢点吃不影响实际顶点 就是虚拟在 shader 中的数据 而 displacement mapping 是实际修改每个 vertex 的位置

放 mapping 会露馅：
首先，在边缘的地方，它虚拟的是凹凸不平的，但是实际的边缘却是平滑的。
其次，它的阴影投影出来是没有任何凹凸变化的。

Displacement mapping 也是有要求的 它要求模型本身的三角形密度要高 不能是很粗的粗模。因为它实际修改的是每个 vertex 的位置 如果模型很粗糙的话 也得不到很好的结果


DirectX API 提供了一种叫 dynamic tessellation 的方案。也就是说 一开始你可以用一个不那么精细的三角形模型 当你需要精细的时候 它就把需要精细的面给你切分出更多更细的三角形。在 Y 轴上 displacement 就可以了 就可以达到很不错的效果

# 几何表示的大概分类 #geometry

![[Pasted image 20261001142648.png]]

## 影视表达

![[Pasted image 20261001142927.png]]

集合的隐式表达法是将点归类，只描述点所满足的特定关系，而不具体指出这个点是哪个点、在哪里。只要满足关系，属于这个分类的点就在这个面上。

进一步地，可以将函数进行推广，抽象为：
1. F = 0 时，在表面上；
2. F < 0 时，在内部；
3. F > 0 时，在外部。




![[Pasted image 20261001143127.png]]


影视表达的弱点在于 很难用第一直觉去感觉出这个几何函数所表达的几何长什么形状

所以进行采样就比较困难 因为你不知道应该采样哪些具体的点


![[Pasted image 20261001143303.png]]

但是隐式的表达有一个好处 就是很容易判断一个点是在内部、外部还是在表面上。虽然你的第一直觉不清楚这个表面具体长什么样子 但是在内外和表面的关系却非常明确 很容易计算





## 显示表呢

![[Pasted image 20261001143455.png]]

与隐式表达不同，显式表达就是将所有的点及其具体位置直接给出来。例如：
1. 一般模型的三角形面：三角形的三个顶点都是可以确定的。
2. 通过参数映射的方式（如上图所示）：将二维平面的一个 UV 映射到三维空间内，存在这样一个映射关系。

![[Pasted image 20261001143723.png]]

显示表达虽然也是函数，但是函数的输入区间是固定的，即 UV 的范围是已知的。在这个范围内就可以进行明确的采样，也就是说，代入数值可以明确得到具体的位置点。

而隐式表达，代入一个数值，不能得到具体的点。

![[Pasted image 20261001143941.png]]

与之对应的显式表达很难判断一个点是在内部、外部还是在上面

根据不同的目的和需要 选择用不同的表示方法

SDF 也是一种隐式表达法。它定义空间中任何一个点都表示一个有符号的值 这个数值的意义就是该点到你想要定义的几何表面的最近距离：正数表示在外面 负数表示在里面


![[Pasted image 20261001145505.png]]

假如说上面三张图，我有一个运动的物体在 A 时刻挡住了左边的 1/3，在 B 时刻挡住了左边的 2/3。现在我想要将其运动做一个 blend 状态，求出在中间时刻是什么状态。

1. 直接进行线性 blend 的情况：
如果直接进行线性的 blend，最左侧是全挡住的，左侧 1/3 是挡住的，右侧 1/3 是没挡住的，中间 1/3 是半挡住的。因为 A 的中间是 0，B 的中间是 1，混合起来是 0.5，这是不符合运动状态的。我们希望的运动状态是挡住了左边的 1/2。

2. 从 SDF 的角度考虑：
下面从 SDF 的角度来考虑问题。
(a) 第一张图：将左边 1/3 处的一条竖线定义为边界 SDF，就可以理解为左侧 1/3 以内的都是负数，右侧 2/3 都是正数。
(b) 第二张图：同理进行定义。
(c) 混合结果：将它们两个进行混合之后，就可以得到最后一张图，0 的位置刚好是在 1/2 处。因为从第一张图来讲，1/2 的位置处它表达的到表面的距离是正的 1/6；在第二张图的话，表达的是负的 1/6。两者混合起来刚好是 0，所以它很清晰地混合出了表面的一种运动状态。



所以这种混合就可以解释上一张图的两个球之间的变化关系了

如果使用 SDF 函数，想求出它的表面，就要找出所有等于 0 的点。但有时候这些点不太好表示，也不太好寻找。

Level sets method 的做法就是将空间内的点进行离散化，离散化之后，通过高斯法或双线性插值找到为 0 的点，这就相当于找到了平面几何的位置。
