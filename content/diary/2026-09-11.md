# 安排多个三角形的光栅化 #computer-graphics 

一个三角形的光栅化在之前已经讲得很清楚。如果有多个三角形，它们之间互相遮挡，你该如何处理？这就要引入可见性与深度测试、Z-buffer 之类的概念

![[Pasted image 20260911153042.png]]

直觉的算法是画家算法。油画家在绘画的时候，先画远处的物体，再画中间的物体，再画近处的物体。先画远处物体，之后中间的物体画出来会遮挡覆盖远处的物体，近处的物体会覆盖远处和中间的物体，层层叠起来。

比如画右侧的一个立方体，先画最远的背面，再画周围的4个面，再画最前面的1个面，也能得到正确的结果。这是画家算法最直觉的地方。


其实对于立方体这个点，我有一点不清楚的地方：最远的地方画出来之后，再画周围的 4 个面，这 4 个面对于你来说都是相同距离的，那怎么样去安排它们的顺序？

现在看起来是对的，因为上面的面比左边的面后画；如果上面的面比左边的面先画，就会产生错误的结果。

![[Pasted image 20260911153436.png]]

实现画家算法的排序需要 n log n 的复杂度。

对于任意两个三角形来说，总是有一个遮挡关系存在，即使不是完全遮挡，哪怕是相互交叉穿插，也总会有一个三角形在另外一个三角形前面的说法——不对不对不对不对！

如果两个三角形相互穿插，就无法定义完整的遮挡关系。因为在穿插的情况下，你不管后画谁，结果都是错的，因为后画的整个三角形会完全覆盖前面的。

穿插是一种情况，上面也是一种情况，也就是说，当 3 个三角形相互遮挡时，画家算法无法进行合理的排序。



![[Pasted image 20260911153750.png]]

Z-buffer 算法就合理解决了这个问题。Z-buffer 对每一个像素都存储了它的深度值，相当于需要一个额外的空间来存储这个深度值。

简而言之，我们假设 Z 都是正数，Z 越小说明离相机越近，Z 越大说明离相机越远。这样的话，无论如何安排绘画的顺序，只要对比 Z 的值：在 surface 上那个像素的 Z 值如果小的话就进行绘制，如果大的话就丢弃。

Frame buffer是最终生成的颜色结果，Depth buffer是最终生成的Z值结果

使用深度缓存的复杂度是 O(n)，听起来不合理，因为任何排序算法至少都需要 O(n log n) 的复杂度。但是这里要澄清一点的是，Z-buffer 并没有进行排序，而是进行了最小值的寻找，所以它遍历一次找到最小值就可以了

![[Pasted image 20260911155227.png]]

深度很多算法一个非常好的性质就是，它和运算的顺序是无关的。不用将三角形进行排序，任意顺序都可以。但如果先划分的话会有优势，因为只需要一次比较，后续就可以直接射击，避免多余的射点运算

这个算法几乎实现在所有的GPU中内建

# 着色要解决的问题 #computer-graphics 

![[Pasted image 20260911160235.png]]

一个物体本身有它自己的固有色，但是它在不同的光照环境中，最终由人或外部观察到的会是不同的颜色。不同的光源、不同的环境，只要外部环境发生一点变化，最终观察到的结果就完全不同，不再是它颜色本身。这一步就是着色（shading）要解决的问题


# 着色的定义 #computer-graphics 

![[Pasted image 20260911160515.png]]

字典上的定义是，引入明暗和颜色的变化叫做 shading，这一点非常贴近于绘画。在图形学这门课中，我们引用的定义是，对一个物体应用不同的材质，即应用材质的过程

最直观的观察可以分为以下两点：

第一点：高光
高光是指从光源到物体表面，再反射到眼睛，且反射角度与观察点的法线一致时，会明显得到一种光的增强效果。高光几乎都是白色的，也就是光源本身的颜色。

第二点：漫反射（Diffuse）
非高光的部分产生了一种漫反射的效果。漫反射也是由光源引起的，但它不像高光那样完全在法线上形成正好的反射角度。
(a) 偏向光源的一侧：打上去的光确实来自于光源。
(b) 远离光源的一侧：理论上照不到光源的直接光，但我们依然可以观察到它。这说明它的光来自于周围的环境，也就是 ambient（环境光）。

因此，这个模型将物体表面分成了两部分：法线偏向光源一侧的，以及法线远离光源一侧的。


![[Pasted image 20260911161757.png]]

进行一个模型的定义，我们是在每一个局部的点去进行着色的。对于每个局部点来说，它是非常非常小的一部分，可以认定为一个平面。

1. 三个单位向量定义的三个方向：
(a) N：定义了表面的法线。
(b) V：定义了点到观测者的方向。
(c) L：定义了点到光源的方向。

2. 表面物体本身的材质参数：
即它本身的固有色。另外还有 shiny，是指它的亮度吗？比如像瓷器、陶瓷和石膏的那种区别，不知道如何精准地翻译，但它是这个着色模型需要的表示材质的参数。


![[Pasted image 20260911161939.png]]

Shading is local，“local”的意思就是说它只考虑局部性。这个点本身根据上面的模型也可以看到，它跟阴影投影没有关系，那是另外的过程，着色只关注于局部的这个点。

在绘画中也可以运用相同的想法：如果先不考虑遮阴影投影的关系，先对面的朝向去做一个着色上的分析，对于立体感的培养也是不错的。

## 慢反射部分

![[Pasted image 20260911162450.png]]

光线打到一个点上，它会向周围所有的方向进行散射，相当于所有的观测者、所有方向都可以观察到


![[Pasted image 20260911162728.png]]

假设我们定义光线沿法线垂直打下来，light per unit 是 1，因为整个面积全部对着光，能接收到最多的光。

但如果发生角度上的倾斜，还是同一个面积在接收，因为光线的密度是一定的，接收到的光量就少了。所以平均下来，light per unit 就会降低。这个值正比于 cosθ（θ 是光线和法线的夹角）：

1. 当夹角 θ = 0° 时：light per unit 就是 1，因为它正对着，能接收到所有的光线。
2. 当光线倾斜时：接收到的光线比正对着要少，更少的光线散布在整个平面上。
3. 当 θ = 90° 时：光线与面平行，基本上就没有光了。
为了更直观地理解这种变化的趋势，我们可以把每一根光线看作代表一定的能量：
4. 当全部照上去的时候，有 6 根分散在地面上；
5. 当倾斜时，中间只有 3 根；
6. 当倾斜到 90° 时，相当于没有。

光线越少，平均下来的能量就越少。它的变化速度是根据 cos 函数来的（cos 函数在 0° 时是 1，在 90° 时是 0），变化趋势是先慢后快：
(a) 前期旋转时，能量减慢的速度较慢，可能转了好几度才减少一点；
(b) 后期旋转时，稍微旋转一点就可能减掉很多根。

这就是在绘画中应用兰伯特定律的最重要的地方


在宏观上也有一个例子，就是夏天和冬天对环境的感知明度问题：
夏天，太阳接近于直射，在北半球就会觉得亮，漫反射厉害。
冬天，太阳是斜射的角度，所以感觉漫反射弱。

这就形成了对“冷”和“暖”这两种感觉的区别。冷暖来自于我们生活的世界，是一种温度感觉，而温度对应了夏天和冬天：

1. 暖：夏天太阳直射，光照充足，温度高。同时，直射光的漫反射强度大，所以人们就将高温度的“暖和”与视觉观察到的这种高亮度的色彩联系到一起。
2. 冷：冬天阳光斜射，能量少，温度低。斜射光线的漫反射弱，所以人们就将低温度与视觉观察到的这种低漫反射联系在一起，称为“冷”。

因此，色彩的冷暖来自于地球对人类的塑造，来自于环境对人类的塑造。人类之所以能有一个统一的感觉认知，正是由于生活的环境对你的影响，决定了你的大脑本身。


# 光是一种能量 #computer-graphics 

![[Pasted image 20260911203605.png]]

光是一种能量点光源，它的能量向四周不断扩散开来。随着距离变远，它会存在一个 fall off，也就是衰减。可以这么理解，衰减就是单位面积上的光线数量的多少。

比如说，最中间那个圆的半径是 1。当半径增大一倍变成 2 的时候，

上面的圆圈示意图表达的含义是：因为光是向外传播的，在某一个时刻，向外传播了一层球层的光光的能量，这一层球壳的能量在时间维度上不断向外扩散，假设能量没有损失，随着时间不断慢慢向远方扩散。我们只观察这一瞬间，这一球层光的能量的传播方式，看它如何在球壳的表面积上散开


![[Pasted image 20260911203829.png]]

所以，结合前面这两者，就可以得到在这个模型下计算漫反射着色的一种方案。它是和观测者的方向没有关系的。

具体计算步骤如下：
1. 首先，计算光从点光源传播到 shading point 的距离，得出有多少能量传播了过来。
2. 然后，再用 shading point 的小平面计算有多少能量被照到，并被这个小平面所吸收。
3. 后面的 max(0, ·) 意思是，如果光来自于背面，就不予考虑。

KD 这个系数表示的是对光反射多少的描述。比如说，如果你将光的能量全部反射出去，那就是 1；如果不能全部反射出去，那就比 1 小

所以，将这个值理解为：假如说 vector3 是 3 通道 RGB 的描述，它就是对 RGB 三个分量分别能反射的强度。如果 R 越大，反射的红光就越多，其他两个分量也是相似的。

因此，这个三通道的 Kd 值在某种意义上就定义了物体的固有色。因为假如一个物体看起来是红色，说明它对红色的反射率是最大的，对其他颜色的反射率最小或没有，所以反射率也定义了物体的固有色。

# 生活中的慢反射 #computer-graphics 

漫反射和观测角度无关，只和光源和物体本身有关。这一点可以从生活中体会到：因为你在生活中是随处走动的，对一个物体的观察方向也是多种多样的。你不会因为突然换了一个角度，就会发现眼前的物体突然变了颜色，这就是漫反射的原理
