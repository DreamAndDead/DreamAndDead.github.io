# MVP矩阵对于绘画透视的帮助理解 #drawing 

简单地对 MVP 矩阵进行理解，比如拍照：
第一步，将大家集合起来做好姿势，这是 M 矩阵；
然后，摆好相机、找好角度，这是 V 矩阵；
最后，按下相机快门键，将三维压缩到二维，这是 P 矩阵。

所以对于绘画透视来说，不要一上来就考虑最终呈现的角度和所有物体，而是一开始先做好一个大致的规划：

1. 比如用三视图从正交投影上去想象物体之间的关系。M
2. 然后在一维一点透视的情况下，把物体关系在画面中做一个大致的梳理。
3. 其次，再开始用二维透视、两点透视和三点透视进行旋转和俯仰视角。



# 游戏只是在玩像素吗 #game-design

你在游玩游戏时看到的画面，只是游戏这个系统本身呈现出来的一种现象、一个视角。就像你观察一个世界一样，你只能看到眼前的东西，但这并不意味着这个 2D 平面就是这个世界本身。

游戏是一个复杂的系统。在游玩的过程中，你和它进行交互，其实是和里面的系统打交道。系统给你呈现了你想看到的那一面，呈现了系统本身的信息。

所以，你不是在和游戏的表象打交道，游玩游戏的本质，是和游戏所代表的系统本身做交互。



# 绘画不是科学，而是感觉 #drawing 

透视是一套数学系统，这没有错，但是我们利用透视不是说要计算到分毫不差，而是说表现出你想要传达的感觉，即所谓的立体感、空间感。

相对地，我们研究光色规律、研究投影、研究明暗，是为了表达光感，表达一种透彻、纯净、朦胧的光的感觉。我们研究物体的颜色、表面的纹理看起来的样子，是表现物体的质感、材质的感觉。


质感比如说是软绵绵的、很坚硬的、漂浮的


归根到底，绘画远远没有现实世界中那么高的复杂度，它不能一无所依地覆盖所有细节，但只需要提炼出精要，表达出相应的感觉就够了。目前来看，我所知的就是立体感和空间感、光感还有质感。

所谓的感觉就是一种形容词。你画的具体物体是名词，而给你的感觉是一种形容词，比如说悲伤的、高昂的、激情澎湃的。这种感觉传达出来，才是绘画的要义


# 漫画与绘画与概念设计 #manga

前面讲到，绘画描述的是一种感觉，强调它是核心要义；但是漫画着重的是故事，即对故事本身的描述。如果一定要描述两者的区别，可以从文学角度来强调：

1. 绘画艺术：
关注的是“形容词”。形容词可以是直白的，也可以是多种复合在一起的。含蓄的表达，就是形容一种高级的感觉。

2. 漫画：
强调的是对剧情的描述，着重描述以下要素：
(a) 空间与主体：地点（相关的背景、场景、物品、人物），以及需要人体绘画工艺的事件。
(b) 时间与情节：需要用文字、相关描述或动作，讲述出当前发生了什么

时间。

强调的是对剧情本身的直白描述，时间、地点、人物、事件

所以着重绘画只是辅助而已，辅助出是作画。这相当于小说直出直给的描写，着重强调的是名词还有动词，包括副词（强调修饰动作的词），对形容词不是关注那么多


至于概念设计师，就更偏向于名词层面了。概念设计强调对世界运行的各个事物的设计原理进行剖析。

比如说，你将一个机械钟表的内部结构拆开，用文字是很难描述出相互之间的作用关系的。所以，你需要用图像的语言去将内部的这种运作原理表达出来，将各个部件的名词描述清楚，并描述清楚它们之间是如何相互作用的。

这就是概念设计，其他的动作或者形容词、副词之类的在这里都是辅助。


一旦将其和文学关联起来，绘画就可以借助文学的语言来思考，而不是完全地借助图像语言来思考。可以先在心中规划出一个方向：

1. 艺术型：可以描述出你想要的感觉，也就是你的目标形容词的感觉。
2. 漫画：必须把事件和剧情描述清楚，明确哪些剧情需要一幅画来呈现，并将时间、地点、人物之类的关键点交代清楚。
3. 概念设计：明确你想要设计的东西是什么，它们是怎样作用在一起的。

提前在这方面打好文字功底，后面的绘画会轻松很多。

# Fov在绘画、透视和摄像中的联系 #computer-graphics  #drawing 

### 1. 核心关系：焦距 ↔ FOV（数学公式）

在摄影中，FOV（视场角）和镜头焦距是数学上的反比关系，通过下面这个公式联系：

**像高 = 焦距 × tan(半FOV)** 

这个公式说明，在相机感光元件尺寸固定的前提下：
*   **焦距越短（广角镜头）** → FOV越大，拍到的景物范围越广。
*   **焦距越长（长焦镜头）** → FOV越小，拍到的景物范围越窄，像在“望远镜”里看东西。

焦距是透镜到感光平面的距离。在感光平面大小不变的情况下，焦距越短，FOV就越大


在使用“焦距 ↔ FOV”的换算关系时，还有一个重要的变量：**感光元件（画幅）的尺寸**。

比如“50mm焦距”在传统135相机上是标准镜头，但在传感器较小的相机上，它就会变成一个视角偏窄的中长焦镜头。因此，**FOV才是描述视野范围的直接标准，而焦距只是一个相对标准**。

### 2. 在绘画透视中的体现

FOV和焦距的选择，直接决定了画面呈现哪种透视感：

*   **“广角”效果（短焦距 → 大FOV）**：这就是画面会产生“近大远小”夸张效果的**三点透视**甚至**五点透视**。强烈的透视感让空间更有张力，但画面边缘的物体会被明显拉伸、变形。一些绘画教程中提到的“鱼眼镜头”效果，正是为了模拟这种广角视觉。
*   **“标准”效果（中等焦距 → 约45°-60° FOV）**：这最接近人眼自然观察的感觉，也就是常见的**一点透视**或**两点透视**。画面透视关系平实、舒服，符合我们日常的视觉经验。
*   **“长焦”效果（长焦距 → 小FOV）**：空间会被“压缩”，画面中远近物体的大小差异变得不明显，透视感很弱。这在绘画中常用于表现远处风景或特写，景深感会大大减弱。

# 使用三角形的优势 #computer-graphics 

![[Pasted image 20260909223825.png]]

三角形是最基础的多边形，其他的多边形都可以打散为三角形。三角形有一些独特的性质：

1. 平面性：三角形一定是一个平面。如果像是四边形，它可能沿对边折一下就不是一个平面。
2. 凸性：三角形一定是凸的，而多边形的话就不一定是凸的，处理起来麻烦。
3. 插值特性：三角形内部任何一个点都可以进行平滑的插值。只要知道三角形 3 个顶点上属性的值，就可以使用重心坐标的插值方法。

# 真实物理设备的RGB分布 #computer-graphics 

![[Pasted image 20260909225958.png]]

iPhone 设备的每一个像素是 RGB 竖状的小块并在一起，三星的 Galaxy 使用的是一种奇妙的布局，叫 bayer pattern

这种 pattern 有一个特点：它的绿色点密度会比红色和蓝色要大。红色和蓝色的密度大约相等，但是绿色的点比它们密很多，相当于绿色的点要多于红和蓝

因为人眼对绿色很敏感，所以使用了这种设计方法。包括很多相机的感光元件也将绿色多放一点，就是利用了人眼的这种特性

在彩色打印机上，则用了更为复杂的pattern
