# 显示几何的表示法 #geometry 

![[Pasted image 20261002104431.png]]

![[Pasted image 20261002104645.png]]

点云表示法就是纯粹用三维空间中的点去表示物体。

本质用一个三维列表就可以表示存储

1. 原理与应用：只要点密度足够大，就可以看到物体的表面。它一般用于作为扫描的 raw 数据，拿到这些 raw 数据之后，一般要进行三角形面的划分。
2. 表现效果：点密度大的时候看起来效果可以，密度小的时候就看不出来是什么。


![[Pasted image 20261002104918.png]]

多边形的面几乎是中医学中最常用的表示方式 一般是用三角形和四边形


![[Pasted image 20261002105055.png]]

在文件中表示这种格式（比如 obj 格式）：
V 表示点的位置；
VT 表示 UV 坐标（即 Texture 坐标）；
VN 表示该点对应的 Normal；
最下面的 F 对应的是它们的连接关系。

三个数字 比如说 511 对应的第一个应该是“点” 第二个应该是“ 纹理坐标” 第三个应该是“normal”

F的意思是face


# 曲线的几何表示 #geometry 


## 贝塞尔曲线

![[Pasted image 20261002105920.png]]

贝塞尔曲线有四个点去定义一条曲线：P0、P1、P2、P3。曲线的方向是从 P0 开始到 P3 结束。曲线开始的切线方向是 P0 到 P1 结束的切线方向是 P2 到 P3


P0和P3是曲线经过的点 P1和P2是控制点


先来看看如何画一条 PCR 曲线。从一个简单的算法开始：二次贝塞尔曲线

Quadratic curve

![[Pasted image 20261002110448.png]]

![[Pasted image 20261002110557.png]]

![[Pasted image 20261002110607.png]]

假设想画从 B0 到 B2 的贝塞尔曲线，控制点是 B1。我们假设从曲线的开始到结束是由一个 T 分量决定的，起点是 0，终点是 1。

所以，我们先找到 B0、B1 上的 T 点，再找到 B1、B2 上的 T 点；然后将这两个点连接成线段，再找到该线段上的 T 点，就得到了这条曲线上 T 所在的位置。

![[Pasted image 20261002110747.png]]

对于cubic curve也是同样的思路


之前显示的都是贝塞尔曲线的直观解释过程。下面可以更具体地通过 4 个点的位置坐标和 T 给出一个代数方程式来描述出点具体的位置

![[Pasted image 20261002111057.png]]

![[Pasted image 20261002111326.png]]


这里可以看到一个很熟悉的展开式：24 的展开式 (1-T)²。观察 (1-T) 和 T 是如何分布的：最开始全是 (1-T)，到后面全是 T，有一个线性的变化过程。

如果到三次方的话，就是 (1-T)³，然后到 (1-T)²T，再到 (1-T)T²，再到 T³。

中间的系数2就来自于杨辉三角多项式中间的那个系数



![[Pasted image 20261002111615.png]]

所以最终就可以抽象出其中的规律 不用每次都手动计算任何高阶的 VCR 曲线 都可以方便地给出它的代数方程

贝塞尔曲线没有必要限定在平面内 也可以放在三维空间内。比如说 4个在三维空间中的点就可以插值出一条曲线


![[Pasted image 20261002111943.png]]

伯恩斯坦方程式本质就是对自己的一个多项式展开

对任意一个横轴上的T来讲 竖轴上四条线的值加起来都是1

![[Pasted image 20261002112614.png]]

贝塞尔曲线的性质：

1. 端点插值：t 取 0 和 1 时，曲线一定是在起点和终点上。
2. 切线方向：起点和终点的切线有一个参数 3，来自于展开的三次项。
3. 仿射变换不变性：对整个贝塞尔曲线做仿射变换，等同于将起点、终点和控制点进行仿射变换后再绘制出来，结果是一样的；但是对于投影变换就不一定。
4. 凸包性：曲线一定是在控制点和起点形成的凸包内。

贝塞尔曲线的连续性：如果两条贝塞尔曲线的端点连接在一起 算是 c0 连续

几何上只要挨在一起就可以

![[Pasted image 20261004104040.png]]

在切线上的连续 要求两边的贝塞尔曲线控制点的线段在一个方向 并且长度相等
这个是C1连续 就是在一阶导数上的连续

制造业有的时候会要求更高级别的连续 比如说二阶导数的连续
