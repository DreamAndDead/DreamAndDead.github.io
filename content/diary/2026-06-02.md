
# build dir seperate with source dir #cmake

> [!PDF|yellow] [[Professional-CMake-21st-CN.pdf#page=23&selection=130,0,132,27&color=yellow|Professional-CMake-21st-CN, p.23]]
> > 更可取的方式是让源码目录和构建目录相互独立，这称为“源外构建”。这种方式将源码和构建输出完全分离，从而避免了源内构建中出现的文件混杂问题


> [!PDF|yellow] [[Professional-CMake-21st-CN.pdf#page=23&selection=132,28,134,19&color=yellow|Professional-CMake-21st-CN, p.23]]
> > 源外构建还有一个优点：开发者可以为同一个源码目录创建多个不同的构建目录。开发者能够使用不同的选项组合来设置构建
>

> [!PDF|yellow] [[Professional-CMake-21st-CN.pdf#page=26&selection=45,21,63,1&color=yellow|Professional-CMake-21st-CN, p.26]]

# add exe target #cmake 

```cmake
# exe target
add_executable(t1
               [WIN32] # link with /subsystem:windows, omit on non-windows system
               [EXCLUDE_FROM_ALL] # all is the set of all targets, when build with
                                  # --target all, don't build this target
                                  # suitable for dev tools and test program
                                  # only specify --target t1 to build
               s1.h
               s1.cpp)
```

# add library target #cmake


```cmake
add_library(l1
            [STATIC or SHARED or MODULE]
            [EXCLUDE_FROM_ALL]
            s2.h
            s2.cpp)
```

shared, gen .dll and import .lib
static, gen .lib
module, gen .dll as plugin, no import .lib


> [!NOTE] best practice
> except module, leave this blank, let user choose build static or shared
> 

```sh
# in config step
cmake -DBUILD_SHARED_LIBS=YES -S . -B ./build
```

```cmake
# set variable in file, don't do this!
set(BUILD_SHARED_LIBS YES) # before add_library(), not flexable as cmd line
```

# target link libraries #cmake


```cmake
target_link_libraries(t1
                      <PRIVATE or PUBLIC or INTERFACE> t2 t3
                      <PRIVATE or PUBLIC or INTERFACE> t4 t5
                      )
```

此处 t1 可以不是 target，而是库文件的绝对路径，如
`/usr/lib/libfoo.so` or `c:/libs/bar.lib`

## 依赖传递关系的区别

| a *which relation* dep on b; c dep on a | private | public | interface |
| --------------------------------------- | ------- | ------ | --------- |
| a.h include b.h                         | ❌       | ✔️     | ✔️        |
| a.cpp include b.h                       | ✔️      | ❌      | ❌         |
| a link b.o                              | ✔️      | ✔️     | ❌         |
| c need include b.h dir                  | ❌       | ✔️     | ✔️        |
| c need link b.o                         | ❌       | ✔️     | ❌         |
