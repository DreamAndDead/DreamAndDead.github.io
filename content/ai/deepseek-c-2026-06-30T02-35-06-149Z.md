## `constexpr` vs `consteval`（C\+\+20）

在 C\+\+20 之前，`constexpr` 是唯一的关键字，用于表示"可以在编译期求值"。但它有一个关键特点：**可以在运行时调用**。C\+\+20 引入的 `consteval` 改变了这一点，它强制函数**必须在编译期执行**。

---

### 1. **核心区别**

| 特性 | `constexpr` \(C\+\+11\) | `consteval` \(C\+\+20\) |
| --- | --- | --- |
| **执行时机** | 可能在编译期，也可能在运行时 | **必须在编译期** |
| **是否可以运行时调用** | ✅ 可以（如果参数是运行时值） | ❌ 不可以 |
| **函数返回值用途** | 可用作常量或变量 | **只能用作常量** |
| **编译失败后果** | 回退到运行时执行 | **编译错误** |
| **调试便利性** | 可在调试器中断 | 无法调试（编译期执行） |

---

### 2. **`constexpr` 的特点**

`constexpr` 函数的返回值**取决于上下文**：

-
如果参数是**编译期常量**，函数在编译期求值
-
如果参数是**运行时变量**，函数退回到运行时执行

cpp

```cpp
constexpr int square(int x) {
return x * x;
}

// 编译期求值（参数是常量）
constexpr int result1 = square(5);  // 编译期计算，result1 = 25

// 运行时求值（参数是变量）
int runtime_value = 10;
int result2 = square(runtime_value);  // 运行时计算

// 也可以用于编译期常量表达式
int arr[square(3)];  // ✅ 编译期求值，arr 大小为 9
```

---

### 3. **`consteval` 的特点（立即函数）**

`consteval` 函数**必须**在编译期执行。如果无法在编译期求值，会导致**编译错误**。

cpp

```cpp
consteval int cube(int x) {
return x * x * x;
}

// ✅ 编译期求值（参数是常量）
constexpr int result1 = cube(3);  // result1 = 27

// ✅ 也可以用于常量表达式
int arr[cube(2)];  // arr 大小为 8

// ❌ 编译错误！参数是运行时变量
int runtime_value = 5;
int result2 = cube(runtime_value);  // 错误：consteval 函数需要常量表达式

// ❌ 编译错误！不能用运行时上下文
int* ptr = new int(cube(runtime_value));  // 错误
```

### 4. **完整示例对比**

cpp

```cpp
#include <iostream>

// constexpr 函数：可以编译期或运行时
constexpr int add_constexpr(int a, int b) {
return a + b;
}

// consteval 函数：必须在编译期
consteval int add_consteval(int a, int b) {
return a + b;
}

int main() {
// 编译期常量
constexpr int x = 10;
constexpr int y = 20;

// constexpr：两种都可以
constexpr int r1 = add_constexpr(x, y);  // ✅ 编译期
int r2 = add_constexpr(x, y);            // ✅ 编译期（编译器自动）
int r3 = add_constexpr(5, 7);            // ✅ 编译期（优化）

// consteval：必须编译期
constexpr int r4 = add_consteval(x, y);  // ✅ 编译期
int r5 = add_consteval(3, 4);            // ✅ 编译期（编译器自动）

// 运行时变量
int a, b;
std::cin >> a >> b;

int r6 = add_constexpr(a, b);   // ✅ 运行时执行（回退）
// int r7 = add_consteval(a, b); // ❌ 编译错误！consteval 需要编译期常量

std::cout << r6 << '\n';
return 0;
}
```

### 5. **`consteval` 的使用场景**

#### 5.1 编译期哈希（字符串哈希）

cpp

```cpp
consteval uint32_t hash_string(const char* str) {
uint32_t hash = 0;
for (; *str; ++str) {
hash = hash * 31 + *str;
}
return hash;
}

constexpr uint32_t h1 = hash_string("hello");  // ✅ 编译期计算
// 运行时调用：hash_string(read_from_user());  // ❌ 编译错误
```

#### 5.2 编译期字符串处理

cpp

```cpp
consteval int string_length(const char* str) {
int len = 0;
while (str[len]) ++len;
return len;
}

constexpr int len = string_length("C++20");  // len = 5
char buffer[string_length("hello") + 1];     // buffer 大小 6
```

#### 5.3 模板元编程辅助

cpp

```cpp
template<int N>
struct Array {
int data[N];
};

consteval int get_array_size(int n) {
return n * 2;
}

Array<get_array_size(5)> arr;  // ✅ 大小 10
```

### 6. **`consteval` 的限制**

cpp

```cpp
// 1. 不能有静态局部变量
consteval int func1() {
// static int x = 10;  // ❌ 错误！不允许静态变量
return 42;
}

// 2. 不能有 try/catch（编译期没有异常处理）
consteval int func2() {
// try { ... } catch (...) { }  // ❌ 不允许
return 42;
}

// 3. 参数必须是字面量类型
consteval int func3(std::string s) {  // ❌ std::string 不是字面量类型
return s.size();
}

// 4. 不能调用 consteval 函数之外的运行时函数
void runtime_func() { }

consteval int func4() {
// runtime_func();  // ❌ 错误！不能调用非 constexpr 函数
return 42;
}

// 5. 不能进行 I/O 操作
consteval int func5() {
// std::cout << "Hello";  // ❌ 错误！I/O 不是 constexpr
return 42;
}
```

### 7. **`if consteval`（C\+\+23）**

C\+\+23 引入 `if consteval`，允许在编译期判断当前是否在编译期上下文中：

cpp

```cpp
#include <iostream>

constexpr void log(const char* msg) {
if consteval {
// 编译期执行
std::cout << "Compile-time: " << msg << '\n';  // 实际不会输出
// 编译期生成代码，但不执行 I/O
} else {
// 运行时执行
std::cout << "Runtime: " << msg << '\n';
}
}

constexpr void test() {
log("test1");  // 在编译期上下文
}

int main() {
log("test2");  // 在运行时上下文
// 输出：Runtime: test2
}
```

### 8. **性能对比**

cpp

```cpp
#include <chrono>
#include <iostream>

// 编译期求值（零运行时开销）
constexpr int compute_crc_constexpr(const char* str) {
int crc = 0;
for (; *str; ++str) {
crc = crc * 31 + *str;
}
return crc;
}

// 运行时求值（有运行时开销）
int compute_crc_runtime(const char* str) {
int crc = 0;
for (; *str; ++str) {
crc = crc * 31 + *str;
}
return crc;
}

int main() {
// constexpr：编译期计算，零开销
constexpr int hash1 = compute_crc_constexpr("Hello");

// 运行时：每次调用都计算
auto start = std::chrono::high_resolution_clock::now();
for (int i = 0; i < 1000000; ++i) {
int hash2 = compute_crc_runtime("Hello");  // 重复计算
}
auto end = std::chrono::high_resolution_clock::now();
// 耗时：约 50ms

// consteval：强制编译期，零开销
constexpr int hash3 = compute_crc_consteval("World");  // 如果有 consteval
}
```

### 9. **最佳实践**

| 场景 | 推荐使用 | 原因 |
| --- | --- | --- |
| **常量表达式** | `constexpr` | 灵活，可用作常量或变量 |
| **编译期哈希** | `consteval` | 强制编译期，避免运行时开销 |
| **编译期字符串处理** | `consteval` | 确保在编译期完成 |
| **模板元编程辅助** | `consteval` | 编译期求值更明确 |
| **需要调试的函数** | `constexpr` | 可在调试器中中断 |
| **可能接受运行时值** | `constexpr` | 可回退到运行时 |

### 10. **总结对比表**

cpp

```cpp
// constexpr：灵活但可能运行时执行
constexpr int square(int x) { return x * x; }

constexpr int r1 = square(5);    // ✅ 编译期
int r2 = square(getValue());     // ✅ 运行时（回退）

// consteval：强制编译期执行
consteval int cube(int x) { return x * x * x; }

constexpr int r3 = cube(5);      // ✅ 编译期
int r4 = cube(getValue());       // ❌ 编译错误！
```

### 核心记忆

> **`constexpr`：可以编译期也可以运行时（灵活）**
> **`consteval`：必须编译期（严格）**

**一句话总结：**

-
**`constexpr`** = "我可以在编译期运行，但如果你用运行时值，我也行"
-
**`consteval`** = "我必须在编译期运行，不接受运行时值"
