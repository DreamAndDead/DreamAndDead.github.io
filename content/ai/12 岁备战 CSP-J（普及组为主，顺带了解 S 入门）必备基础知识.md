# 12 岁备战 CSP-J（普及组为主，顺带了解 S 入门）必备基础知识

分三块：**C++ 编程语言基础、数学基础、基础算法思维**，完全贴合初一 / 六年级孩子的接受能力，我把必学内容、门槛、学到什么程度讲清楚，避开无用内容。

## 一、编程语言：必须精通 C++（竞赛唯一主力）

CSP 全程用 g++，不要用 Python 当主力，Python 只能用来验算。

### 必掌握完整知识点（J 组全覆盖）

1. **基础语法**
   - 数据类型：int、long long（重中之重，防溢出）、char、bool、double，必须分清数值范围，12 岁最容易犯 int 爆掉的低级错误；
   - 输入输出：cin/cout，进阶必须学会**快读快写**（竞赛提速必备）；
   - 运算符：算术、取模 %、整除、位运算 (& | ^ <<>>)，取模、位运算是信奥高频考点。
2. **三大程序结构** 顺序、分支（if/else、switch）、循环（for、while、do while），熟练嵌套循环。
3. **数组与字符串** 一维数组、二维数组、字符数组 string，数组下标、边界判断（越界是新手重灾区），字符串读写、拼接、比较。
4. **函数** 自定义函数、形参实参、返回值、全局 / 局部变量，熟练写递归函数（DFS 核心）。
5. **指针可以不学**，**STL 容器必须吃透（J 组核心）** 必考容器：
   - sort 排序、swap；vector 动态数组；queue 队列、stack 栈；
   - priority_queue 优先队列（堆）；map、set 简单使用； 万能头 `#include<bits/stdc++.h>` 竞赛标配写法要熟练。
6. 简单文件读写（了解即可，正式比赛统一标准输入输出）

### 学习达标标准

随便给一道模拟题，能独立手写完整代码，会调试语法 bug，能看懂编译报错。

## 二、配套数学知识（小学奥数 + 初中课内数学，12 岁刚好对应）

CSP 本质是**数学 + 编程**，数学跟不上，代码写得再好也没用。

### CSP-J 必备数学

1. **课内基础（六年级～初一）** 整数四则运算、最大公约数 gcd、最小公倍数 lcm、质数合数、因数分解、余数（模运算），奇数偶数、不等式。
2. **小学奥数核心模块（必考）**
   - 数论入门：质数判断、筛法、辗转相除法；
   - 组合数学：排列、组合、简单计数、容斥原理；
   - 逻辑推理、枚举思路、简单贪心数学证明。
3. **简单几何** 平面坐标、两点距离、矩形 / 三角形面积、坐标计算。

### CSP-S 提高组前置数学（有余力提前接触）

快速幂、模逆元、进制转换、简单概率、初等代数，不用深挖，先留印象。

## 三、核心算法（CSP-J 全部考点，循序渐进学）

按学习顺序，新手完全可以一步步攻克：

### 入门第一层（最简单，必拿分）

1. **枚举暴力**：全遍历、模拟，J 组大量简单题都是模拟，上手第一个算法；
2. **排序**：冒泡、选择、插入理解原理，日常直接用 STL sort；
3. **二分查找**：二分答案是 J 组中档高频题，必须熟练。

### 第二层（重难点）

1. **搜索算法** DFS 深度优先（递归）、BFS 广度优先（队列），迷宫、路径、子集问题必考，是 J 组压轴常客；
2. **贪心算法**：区间问题、排队、最值选择，思路好懂，关键判断贪心策略是否正确。

### 第三层（J 组压轴，冲一等奖必备）

1. **动态规划 DP 入门**：01 背包、最长上升子序列、简单线性 DP，不需要难题，吃透基础模型即可；
2. **简单图论**：邻接表 / 邻接矩阵存图，最短路入门（Floyd、朴素 Dijkstra）；
3. **哈希、前缀和、差分**，数组区间查询神器，做题效率翻倍。

### S 组拓展内容（后期进阶）

并查集、单调队列、进阶 DP、拓扑排序、字符串 KMP 等，J 阶段不用硬学。

## 四、附加必备软能力（12 岁孩子容易忽略）

1. **读题能力**：能把文字题目，转换成数学模型，分清输入输出格式、数据范围；
2. **调试能力**：会打断点、输出中间变量，定位代码错误，不怕 bug；
3. **估算数据范围**：看 n 的大小判断用什么算法（n≤1000 可以暴力，n≥1e5 绝对不能暴力），初步判断会不会超时；
4. **规范做题习惯**：变量命名清晰、代码缩进规整，预留测试样例自测。

## 五、给 12 岁孩子的学习规划路线（适配六年级 / 初一）

1. 前期 1~2 个月：搞定完整 C++ 语法 + STL，语法不通不要碰算法；
2. 中期 2~3 个月：刷基础模拟、枚举、排序题，同步补对应数学；
3. 后期主攻 DFS/BFS、贪心、二分，刷洛谷 CSP-J 真题，冲刺二等奖 / 一等奖；
4. J 组稳定获奖后，再慢慢接触 S 组内容，不要一开始就越级硬冲 S。

## 六、常见误区提醒

1. 不要先用 Python 学算法再转 C++：后期改语法习惯成本极高，竞赛速度硬伤；
2. 不要只背模板不理解原理：CSP 出题灵活，只会套模板遇到变形题直接崩盘；
3. 文化课优先：初中课内数学学好，算法会事半功倍，不要完全脱离课内学习。
