## User

telescope run custom defined  functions

## Assistant

在 `telescope.nvim` 中运行自定义函数，其实就是把你定义的 Lua 函数放到 Telescope 的 `finder` 或 `picker` 里，让它成为一个可以交互的选择项。这样做的好处是，你可以把一些常用的操作（比如打开特定文件、执行某个命令）都放到 Telescope 的统一界面里来管理和调用。

实现这个功能，主要会用到 `telescope` 的 **`finders`** 和 **`pickers`** 模块。下面是一个基础示例，演示如何让 Telescope 列出并运行你的自定义函数。

### 🧩 基础示例：运行自定义函数列表

假设你定义了几个常用的函数，想通过 Telescope 来快速调用它们：

lua

```lua
-- 1. 定义一些自定义函数
local my_functions = {
{ name = "Say Hello", action = function() print("Hello from Telescope!") end },
{ name = "Open Config", action = function() vim.cmd("edit ~/.config/nvim/init.lua") end },
{ name = "Toggle Spell Check", action = function() vim.opt.spell = not vim.opt.spell:get() end },
}

-- 2. 创建 Telescope 选择器
local function run_custom_function()
require("telescope.pickers").new({}, {
prompt_title = "Run Custom Function",
finder = require("telescope.finders").new_table({
results = my_functions,
entry_maker = function(entry)
return {
value = entry,
display = entry.name,
ordinal = entry.name,
}
end,
}),
sorter = require("telescope.config").values.generic_sorter({}),
attach_mappings = function(_, map)
map("i", "<CR>", function(prompt_bufnr)
local entry = require("telescope.actions.state").get_selected_entry()
if entry then
entry.value.action()  -- 执行自定义函数
end
require("telescope.actions").close(prompt_bufnr)
end)
return true
end,
}):find()
end

-- 3. 绑定快捷键
vim.keymap.set("n", "<leader>rf", run_custom_function, { desc = "Run custom functions" })
```

### 🚀 进阶用法：动态生成函数列表

如果你希望函数列表是根据当前上下文动态生成的（比如当前打开的文件类型），可以在 `finder` 中编写更复杂的逻辑：

lua

```lua
local function get_contextual_functions()
local filetype = vim.bo.filetype
if filetype == "lua" then
return {
{ name = "Lint Lua", action = function() print("Linting Lua...") end },
{ name = "Format Lua", action = function() print("Formatting Lua...") end },
}
elseif filetype == "cpp" then
return {
{ name = "Compile C++", action = function() print("Compiling...") end },
{ name = "Run C++", action = function() print("Running...") end },
}
else
return {
{ name = "Default Action", action = function() print("No specific action for this filetype") end },
}
end
end

-- 然后在 picker 中使用 get_contextual_functions() 来动态生成 results 表
```

### 💡 在 LazyVim 中配置

在 LazyVim 中，你可以把这个功能放到 `~/.config/nvim/lua/plugins/telescope.lua` 或 `~/.config/nvim/lua/config/telescope.lua` 中。LazyVim 会自动加载这些配置，前提是你把 `run_custom_function` 这个函数放在一个合适的地方，然后绑定快捷键。

### 🧠 理解关键组件

-
**`finder`**：提供数据源。`new_table` 是最常用的方法，它从 Lua 表中读取数据。
-
**`entry_maker`**：把表中的每一项转换成 Telescope 能显示的条目，包含 `display`（显示的文本）、`ordinal`（排序依据）和 `value`（存储的原始数据）。
-
**`attach_mappings`**：定义在 Telescope 窗口中的按键行为。`map("i", "<CR>", ...)` 定义了在插入模式下按回车键时执行的动作，其中 `get_selected_entry` 获取当前选中的条目。

这种方式的优势在于，你可以把任意复杂的逻辑都封装成一个可调用的函数，然后通过 Telescope 这个统一的入口来访问它们，非常灵活。你可以根据自己的需求，逐渐增加更多自定义函数到列表中。
