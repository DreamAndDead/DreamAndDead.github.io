# 完整 4 种方法，一步步判断你的显示器是否支持 G-Sync（含原生 G-Sync / G-Sync 兼容）

前提：**必须是 NVIDIA 显卡（GTX10 系及以上、全系 RTX）**，AMD 显卡无法使用 G-Sync，只能用 FreeSync。
 同时优先用**DP 线直连显卡 DP 口**，HDMI 绝大多数型号无法完整开启 G-Sync。

## 方法 1：英伟达控制面板（最准，软件直接识别，首选）

1. 桌面空白处右键，打开 **NVIDIA 控制面板**
2. 左侧【显示】→ 点击 **设置 G-SYNC**
3. 观察页面状态：

### 情况 A：页面正常出现选项

可以勾选「**启用 G-SYNC、G-SYNC 兼容**」，下拉能选中你的显示器
 ✅ 你的屏幕支持：原生 G-Sync 或者 **G-Sync Compatible（兼容，即 FreeSync 屏幕被 N 卡认证）**

### 情况 B：页面空白、无选项、提示无兼容显示器

❌ 不支持 G-Sync，大概率只是普通固定刷新率屏幕，或线材 / 接口错误。

### 验证是否成功生效

顶部菜单栏【显示】→ **显示 G-SYNC 视觉指示器**
 进入游戏全屏，屏幕角落会弹出绿色小图标：

- 标注 `G-SYNC` = 原生硬件 G-Sync 屏幕
- 标注 `G-SYNC Compatible` = 认证的 FreeSync 兼容屏 图标出现，代表当前 G-Sync 正在正常运行NVIDIA。

## 方法 2：查看显示器机身 OSD 菜单（判断底层是否带 VRR/FreeSync）

G-Sync 兼容的本质是显示器自带 **Adaptive-Sync / FreeSync（VRR 可变刷新率）**。

1. 按显示器自带实体按键（摇杆 / MENU 键），打开屏幕内置菜单
2. 进入【游戏设置】【图像设置】
3. 查找选项：`FreeSync` / `Adaptive Sync` / `VRR`

- 能找到开关选项：硬件本身支持可变刷新率，可以开启 N 卡 G-Sync 兼容
- 完全没有该类选项：硬件不支持 VRR，**绝对无法使用 G-Sync**。

## 方法 3：查显示器型号官方参数（终极兜底判定）

1. Win+X 打开【设备管理器】→ 展开【监视器】，查看完整显示器型号
2. 去品牌官网（AOC、华硕、戴尔、LG、三星等）搜索型号规格 看参数栏关键词：
3. **G-SYNC / G-SYNC Ultimate**：原生英伟达专用 G-Sync（自带芯片，顶级）
4. **G-SYNC Compatible**：英伟达官方认证兼容屏
5. **FreeSync / FreeSync Premium / Adaptive-Sync**：AMD 标准可变刷新率，N 卡可以开兼容 G-Sync 无以上字样 = 完全不支持 VRR/G-Sync。

## 方法 4：Windows 系统设置辅助确认 Win10/11

1. 设置 → 系统 → 显示 → 图形设置 → **默认图形设置**
2. 查看是否存在【**可变刷新率（VRR）**】开关 有开关 = 系统识别到显示器支持自适应同步；无开关则硬件不支持。

# 常见踩坑：明明显示器支持，N 卡面板却没有 G-Sync 选项

1. **线材 / 接口错误（最高发）** G-Sync 优先 **DP1.2a 及以上直连线材**；普通 HDMI 2.0 大多不支持，HDMI2.1 新款电视 / 高端显示器才支持 HDMI 的 G-Sync；**DP 转 HDMI 转接头基本无法开启**。
2. 外接笔记本：画面核显输出 笔记本必须在 NVIDIA 控制面板【管理 3D 设置】，把游戏程序指定为**NVIDIA 高性能显卡**运行，核显输出无法启用 G-Sync。
3. 驱动老旧 更新最新 NVIDIA 显卡驱动，旧驱动识别不全兼容屏幕。
4. 显示器当前输入口选错 OSD 菜单确认当前信号输入为 DP，不要插在 HDMI 口。

# 补充区分原生 G-Sync 和 G-Sync 兼容

1. **原生 G-Sync**：显示器内置英伟达专用芯片，刷新率区间更广、低帧率防黑屏（LFC）、稳定性拉满，价格贵。
2. **G-Sync Compatible**：普通 FreeSync 显示器经过英伟达认证，性价比主流选择，日常游戏体验差距极小。
3. 未认证的杂牌 FreeSync 屏：可在 N 卡面板强行手动开启兼容，可能出现闪屏、黑屏，不推荐。
