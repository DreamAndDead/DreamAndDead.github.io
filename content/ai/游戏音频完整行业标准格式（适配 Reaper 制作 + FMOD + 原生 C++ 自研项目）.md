# 游戏音频完整行业标准格式（适配 Reaper 制作 + FMOD + 原生 C++ 自研项目）

分为**制作母版标准参数**、**正式成品编码格式**、**分场景选型**、**各平台专属规范**四部分，直接落地使用。

## 一、母版工程制作标准（Reaper 工程固定参数，必须严格统一）

所有编曲、分层音效、配音，**工程母版一律使用这套参数**，是行业通用黄金标准：

1. **采样率：48000Hz（48kHz）** 游戏、影视通用标准，完美适配 PC、手游、主机全平台，不要用 44.1kHz（CD 标准），避免引擎重采样损耗音质。
2. **位深度：24bit** 混音动态余量充足，后期压缩、EQ 处理不会产生量化噪音；引擎运行时最终输出为**16bit**，母版 24bit 预留处理空间。
3. **声道规则**
   - 3D 空间音效（脚步声、怪物、技能）：**单声道 Mono**（必须单声道，3D 空间定位精准）
   - BGM 背景音乐、全局环境氛围乐：**立体声 Stereo**
   - UI 提示音、全局语音：统一单声道。
4. 母版容器：**WAV PCM 无损**，全程英文路径，作为原始素材存档。

## 二、两大核心成品格式（游戏打包最终使用）

### 1. WAV（PCM 无压缩）

后缀 `.wav`，**原始未压缩 PCM 波形数据**

#### 适用场景：短瞬态音效（时长＜2 秒）

UI 点击、普攻、枪声、暴击、按钮音效等短音效。

- 优点：**零 CPU 解码开销、零播放延迟、触发瞬间响应最快**，FMOD / 自研音频 SDK 可以直接读取波形，手感最优；
- 缺点：体积大，只适合短小音频；
- 成品参数：48kHz / 16bit Mono，游戏最终运行位深统一 16bit。 衍生精简格式：**IMA ADPCM WAV**，4:1 轻量化压缩，解码速度接近 PCM，手游大量音效首选折中方案。

### 2. OGG Vorbis（开源首选，游戏行业主流压缩格式）

后缀 `.ogg`，**专利完全免费开源**，是游戏 BGM、长语音、环境 Loop 的标配，碾压 MP3 作为游戏首选压缩格式。

#### 码率标准（直接抄参数）

1. 背景音乐 BGM（立体声）：**192~256kbps**，音质透明，人耳几乎听不出压缩损耗；
2. 剧情 NPC 语音（单声道）：**96~128kbps**，人声足够清晰，体积极小；
3. 长环境氛围音：128~160kbps。

#### 核心优势

- 相同音质下，体积比 MP3 更小；
- 完美支持流式播放、无缝循环 Loop，天生适配游戏循环 BGM；
- FMOD、SoLoud、所有自研 C++ 音频库原生完美支持，商用无版权费用。

## 三、其他格式用途（备用 / 平台专属）

1. **Opus(.opus)** 压缩效率天花板，低码率音质极强，适合手游网络语音、移动端小体积语音包；FMOD 新版完整支持，新项目可以优先备选 OGG。
2. **AAC(.m4a)** 安卓 /iOS 原生硬解码效率高，**苹果 / 手游 iOS 平台专属备用**，移动端打包备选方案，不做 PC 游戏主力格式。
3. **FLAC 无损压缩** 仅用于素材备份存档，**绝对不要打包进游戏运行**，体积过大，没有必要。
4. **MP3** 游戏开发尽量规避，压缩效率不如 OGG，历史专利遗留问题，仅做老旧引擎兼容备用。
5. 主机专属封装（主机平台编译自动转） Xbox：XMA；PlayStation：ATRAC；Switch：BFSTM，FMOD 会自动跨平台编码，设计师只需要输出标准 WAV/OGG 即可。

## 五、Reaper 导出流程（对接 FMOD 标准流水线）

1. **制作阶段**：Reaper 工程 48kHz/24bit，分层轨道导出**24bit WAV 母版**，存入素材库；
2. **导入 FMOD Studio**：使用无损 WAV 制作 Event 分层、RTPC 交互逻辑；
3. **打包发布前编码**： FMOD 内置编码器，可在打包 Bank 时，自动把素材批量编码为 OGG/ADPCM，无需手动二次转换；
4. 最终运行：游戏 Runtime 解码播放，PCM 音效常驻内存，长 BGM 流式加载。

## 六、PC 端 / 移动端 平台差异化规范

### PC 端自研 C++ 项目（你的项目）

1. 短音效：**16bit 48kHz Mono WAV**，常驻内存，追求最低延迟手感；
2. BGM / 语音：OGG 流式读取硬盘，节省内存；
3. 声道全开支持立体声完整声场。

### 安卓 /iOS 手游（性能严格受限）

1. 90% 音效全部**强制单声道**，大幅降低 3D 运算 CPU 开销；
2. 大批量音效改用 **IMA ADPCM** 压缩，平衡体积与解码性能；
3. 语音统一低码率 OGG，最高码率不要超过 128kbps，控制安装包体积。

## 七、高频避坑误区

1. 不要用 44.1kHz 成品：引擎强制重采样转为 48kHz，会额外消耗 CPU、引入音质损伤；
2. 3D 音效严禁立体声：立体声做 3D 空间定位算法会错乱，方位判断失效；
3. 不要把成品混音响度拉满：响度、动态混音交给 FMOD 运行时总线控制，母版预留动态空间；
4. 禁止中文文件名 / 路径：WAV、OGG 文件名全程英文，否则 FMOD、C++ 读取文件失败。

## 最简总结口诀

**制作母版 48k 24bit WAV，短音效 WAV 保延迟，长音频 OGG 省空间，3D 音效必单声道，BGM 语音立体声。**
