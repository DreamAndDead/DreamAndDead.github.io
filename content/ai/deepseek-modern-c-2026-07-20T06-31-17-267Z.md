## `enum class` 详解：现代 C\+\+ 的强类型枚举

`enum class` 是 C\+\+11 引入的一种枚举类型，也被称为**作用域枚举（Scoped Enumeration）**或**强类型枚举（Strongly Typed Enum）**。它是对传统 `enum` 的全面改进，旨在解决传统枚举的多个缺陷。

---

### 1. **`enum class` 的核心特性**

| 特性 | 说明 |
| --- | --- |
| **作用域隔离** | 枚举值不会暴露到外层命名空间，必须通过 `EnumName::Value` 访问 |
| **类型安全** | 不会隐式转换为整数，需要显式转换（`static_cast`） |
| **可指定底层类型** | 可以显式指定底层整数类型（如 `unsigned char`、`short`） |
| **可前置声明** | 支持前置声明（不完整类型），便于减少编译依赖 |

---

### 2. **传统 `enum` 的缺陷**

#### 缺陷 1：作用域污染

cpp

```cpp
enum Color { Red, Green, Blue };
enum Status { Red, Error, OK };  // ❌ 编译错误！Red 重复定义
```

#### 缺陷 2：隐式转换为整数

cpp

```cpp
enum Color { Red, Green, Blue };
int x = Red;           // 隐式转换为 0
if (Red == 0) { ... }  // 可以比较，但语义错误
```

#### 缺陷 3：底层类型不确定

cpp

```cpp
enum Color { Red, Green, Blue };
static_assert(sizeof(Color) == ?);  // 未指定，可能 1、2、4 字节
```

#### 缺陷 4：不支持前置声明

cpp

```cpp
// ❌ 传统枚举不能前置声明
enum Color;  // 编译错误
```

---

### 3. **`enum class` 如何解决这些问题**

#### 3.1 作用域隔离

cpp

```cpp
enum class Color { Red, Green, Blue };
enum class Status { Red, Error, OK };  // ✅ 可以，作用域隔离

// 使用时必须加作用域
Color c = Color::Red;      // ✅
Status s = Status::Red;    // ✅
// Color c = Red;          // ❌ 错误！不能直接使用
```

#### 3.2 类型安全

cpp

```cpp
enum class Color { Red, Green, Blue };

// int x = Color::Red;     // ❌ 错误！不能隐式转换
int x = static_cast<int>(Color::Red);  // ✅ 显式转换
```

#### 3.3 可指定底层类型

cpp

```cpp
enum class Color : unsigned char { Red, Green, Blue };
static_assert(sizeof(Color) == 1);  // 1 字节

enum class Big : unsigned long long { A = 1ULL << 60, B };
static_assert(sizeof(Big) == 8);  // 8 字节
```

#### 3.4 支持前置声明

cpp

```cpp
// 前置声明（需要指定底层类型）
enum class Color : int;

// 后续定义
enum class Color : int {
    Red,
    Green,
    Blue
};
```

---

### 4. **枚举的底层类型**

`enum class` 允许显式指定底层整数类型（C\+\+11 起），且**默认是 `int`**：

cpp

```cpp
// 默认：int
enum class DefaultEnum { A, B, C };
static_assert(sizeof(DefaultEnum) == sizeof(int));  // 通常 4 字节

// 显式指定
enum class Small : unsigned char { A, B, C };
enum class Large : unsigned long long { A, B, C };

static_assert(sizeof(Small) == 1);   // 1 字节
static_assert(sizeof(Large) == 8);   // 8 字节
```

**传统 `enum`** 的底层类型是**未指定的**，由编译器决定，通常取决于枚举值的范围，可能造成跨平台问题。

### 5. **位掩码（Bitmask）场景**

`enum class` 也可以用作位掩码，但需要重载位运算符：

cpp

```cpp
enum class Permission : unsigned int {
    Read   = 1 << 0,
    Write  = 1 << 1,
    Execute = 1 << 2,
    All    = Read | Write | Execute
};

// 重载位运算符（非成员）
inline Permission operator|(Permission a, Permission b) {
    return static_cast<Permission>(
        static_cast<unsigned int>(a) | static_cast<unsigned int>(b)
    );
}

inline bool hasPermission(Permission user, Permission required) {
    return (static_cast<unsigned int>(user) & static_cast<unsigned int>(required)) != 0;
}

int main() {
    Permission p = Permission::Read | Permission::Write;
    if (hasPermission(p, Permission::Write)) {
        // ...
    }
}
```

### 6. **`using enum`（C\+\+20）**

C\+\+20 允许使用 `using enum` 将枚举值引入当前作用域，简化代码：

cpp

```cpp
enum class Color { Red, Green, Blue };

void printColor(Color c) {
    using enum Color;  // C++20
    switch (c) {
        case Red:   std::cout << "Red\n"; break;
        case Green: std::cout << "Green\n"; break;
        case Blue:  std::cout << "Blue\n"; break;
    }
}
```

### 7. **与 `std::underlying_type` 结合**

获取枚举的底层类型，便于编写泛型代码：

cpp

```cpp
#include <type_traits>

enum class Color : unsigned char { Red, Green, Blue };

using ColorType = std::underlying_type_t<Color>;  // unsigned char

void printValue(Color c) {
    auto val = static_cast<ColorType>(c);  // 获取底层数值
    std::cout << "Value: " << static_cast<int>(val) << "\n";
}
```

### 8. **完整对比表**

| 特性 | 传统 `enum` | `enum class` |
| --- | --- | --- |
| **作用域** | 暴露到外层作用域 | 限定在枚举类作用域（`Enum::Value`） |
| **隐式转换为整数** | ✅ 可以 | ❌ 不可以（需 `static_cast`） |
| **底层类型** | 未指定（编译器决定） | 可指定（默认 `int`） |
| **前置声明** | ❌ 不支持（C\+\+11 前） | ✅ 支持 |
| **类型安全** | 低（可与整数混用） | 高（不能与整数混用） |
| **与 C 兼容** | ✅ 兼容 | ✅ 兼容（需显式转换） |
| **推荐用法** | C 风格接口、位掩码（简单场景） | 绝大多数现代 C\+\+ 场景 |

#### 示例 2：错误码

cpp

```cpp
enum class ErrorCode : int {

ErrorCode doSomething() {

    ErrorCode err = doSomething();

    }
```

### 10. **总结与建议**

> **现代 C\+\+ 中，优先使用 `enum class` 而非传统 `enum`。**
> **只有当需要与 C 代码交互，且必须保持纯整数值兼容时，才考虑传统 `enum`。**

| 场景 | 推荐 |
| --- | --- |
| 新项目 | ✅ 全部使用 `enum class` |
| 位掩码 | `enum class` \+ 重载运算符 |
| C 接口 | 传统 `enum` 或 `enum class` \+ 显式转换 |
| 与库交互 | 遵循库的约定（通常是传统 `enum`） |
| 不需要作用域/类型安全 | 考虑 `enum class`（现代风格） |
