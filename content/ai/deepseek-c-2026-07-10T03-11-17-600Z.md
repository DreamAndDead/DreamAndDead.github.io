## 非成员函数重载 vs 成员函数重载

这是 C\+\+ 运算符重载中最核心的问题。两种方式有本质区别，选择哪种取决于**运算符的语义**和**使用场景**。

---

### 1. **核心区别总结**

| 对比维度 | 成员函数 | 非成员函数 |
| --- | --- | --- |
| **左操作数** | `this`（必须是类类型） | 作为第一个参数 |
| **隐式转换** | 只转换右操作数 | **左右操作数都能转换** |
| **访问权限** | 可以访问 private 成员 | 需要 `friend` 或 public 接口 |
| **所有权** | 属于类的一部分 | 独立的函数 |
| **适用运算符** | `=`, `[]`, `->`, `()` | `+`, `-`, `*`, `==`, `<<` |

---

### 2. **关键区别：隐式类型转换**

这是最重要的区别！

#### 成员函数：只能转换右操作数

cpp

```cpp
struct Vector {
double x, y;
Vector(double x = 0, double y = 0) : x(x), y(y) {}

// 成员函数重载 +
Vector operator+(const Vector& other) const {
return Vector(x + other.x, y + other.y);
}
};

int main() {
Vector v(1, 2);

// ✅ 可以：右操作数隐式转换 (3.0 -> Vector(3.0, 0))
Vector r1 = v + 3.0;   // (4, 2)

// ❌ 错误：左操作数不能隐式转换！
// Vector r2 = 3.0 + v;   // 编译错误！
}
```

**为什么？** 因为成员函数的 `this` 必须指向一个 `Vector` 对象，`3.0` 不是 `Vector`，编译器无法在调用 `operator+` 之前将 `3.0` 转换为 `Vector`。

#### 非成员函数：左右操作数都能转换

cpp

```cpp
struct Vector {
double x, y;
Vector(double x = 0, double y = 0) : x(x), y(y) {}
};

// 非成员函数重载 +
Vector operator+(const Vector& a, const Vector& b) {
return Vector(a.x + b.x, a.y + b.y);
}

int main() {
Vector v(1, 2);

// ✅ 可以：右操作数转换
Vector r1 = v + 3.0;   // (4, 2)

// ✅ 可以：左操作数转换！
Vector r2 = 3.0 + v;   // (4, 2)
}
```

**为什么？** 非成员函数的两个参数地位平等，编译器可以对任一参数进行隐式转换。

### 3. **不同运算符的推荐用法**

| 运算符 | 推荐方式 | 原因 |
| --- | --- | --- |
| `=`, `+=`, `-=`, `[]`, `()`, `->` | **成员函数** | 必须修改 `this`，左操作数不能是临时对象 |
| `+`, `-`, `*`, `/`, `%` | **非成员函数** | 需要支持左右操作数的隐式转换 |
| `==`, `!=`, `<`, `>` | **非成员函数** | 保持对称性，左右操作数地位平等 |
| `<<`, `>>` | **非成员函数** | 左操作数是 `std::ostream`/`std::istream` |
| `*` \(解引用\), `&` \(取地址\) | **成员函数** | 操作的是对象本身 |

### 4. **赋值运算符（`operator=`）必须是成员函数**

cpp

```cpp
struct MyClass {
// ✅ 必须是成员函数
MyClass& operator=(const MyClass& other) {
if (this != &other) {
// 拷贝数据
}
return *this;
}
};

// ❌ 编译错误！赋值运算符不能是非成员
// MyClass& operator=(MyClass& a, const MyClass& b);
```

---

### 5. **下标运算符（`operator[]`）必须是成员函数**

cpp

```cpp
struct Array {
int data[10];

// ✅ 必须是成员函数
int& operator[](size_t index) {
return data[index];
}

const int& operator[](size_t index) const {
return data[index];
}
};
```

---

### 6. **函数调用运算符（`operator()`）必须是成员函数**

cpp

```cpp
struct Adder {
int base;

// ✅ 必须是成员函数
int operator()(int x, int y) const {
return base + x + y;
}
};
```

### 7. **完整示例：混合使用**

cpp

```cpp
#include <iostream>

struct Complex {
double real, imag;

Complex(double r = 0, double i = 0) : real(r), imag(i) {}

// 1. 成员函数：+= 修改自身
Complex& operator+=(const Complex& other) {
real += other.real;
imag += other.imag;
return *this;
}

// 2. 成员函数：下标访问（假设返回模长）
double operator[](size_t idx) const {
return idx == 0 ? real : imag;
}

// 3. 成员函数：类型转换
explicit operator double() const {
return std::sqrt(real*real + imag*imag);
}
};

// 4. 非成员函数：+ 对称
Complex operator+(const Complex& a, const Complex& b) {
Complex result = a;
result += b;
return result;
}

// 5. 非成员函数：== 对称
bool operator==(const Complex& a, const Complex& b) {
return a.real == b.real && a.imag == b.imag;
}

// 6. 非成员函数：<< 左操作数是 ostream
std::ostream& operator<<(std::ostream& os, const Complex& c) {
os << "(" << c.real << (c.imag >= 0 ? "+" : "") << c.imag << "i)";
return os;
}

int main() {
Complex a(1, 2);
Complex b(3, 4);

// 使用 +（非成员）
Complex c = a + b;           // (4+6i)
Complex d = a + 5.0;         // ✅ 右操作数转换 (6+2i)
Complex e = 5.0 + a;         // ✅ 左操作数转换 (6+2i)

// 使用 +=（成员）
a += b;                       // a = (4+6i)

// 使用 ==（非成员）
if (a == b) {
std::cout << "相等\n";
}

// 使用 []（成员）
std::cout << "real: " << c[0] << ", imag: " << c[1] << "\n";

// 使用 <<（非成员）
std::cout << c << std::endl;  // (4+6i)

return 0;
}
```

### 8. **总结：如何选择？**

#### 选择成员函数的场景：

1.
运算符必须修改 `this`（如 `+=`, `-=`, `=`）
2.
运算符必须是成员（如 `[]`, `()`, `->`, `=`）
3.
左操作数必须是当前类类型，且不希望支持隐式转换

#### 选择非成员函数的场景：

1.
运算符是二元的且对称的（如 `+`, `==`, `<`）
2.
需要支持左操作数的隐式转换（如 `3.0 + v`）
3.
左操作数是其他类型（如 `std::ostream`）

### 核心记忆

> **成员函数：左操作数是 `this`，只能转换右边**
> **非成员函数：左右平等，两边都能转换**
> **赋值、下标、调用必须成员**
> **算术、比较、流输出用非成员**
