## C\+\+ 类型转换操作符详解

C\+\+ 提供了四种命名的强制类型转换操作符，它们比 C 风格的强制转换（`(type)value`）更安全、更明确，也更易于查找和维护。

---

### 1. **四种 Cast 对比表**

| 转换操作符 | 用途 | 安全性 | 运行时开销 |
| --- | --- | --- | --- |
| **`static_cast`** | 基本类型转换、隐式转换的逆转换 | 编译时检查 | 无 |
| **`dynamic_cast`** | 多态类型的向下转换（基类→派生类） | 运行时检查（RTTI） | 有（RTTI） |
| **`const_cast`** | 添加或移除 `const` / `volatile` 限定符 | 危险！ | 无 |
| **`reinterpret_cast`** | 低级别重新解释（不相关的类型） | 极度危险！ | 无 |

---

### 2. **`static_cast`：最常用，最安全**

#### 2.1 基本类型转换

cpp

```cpp
int i = 10;
double d = static_cast<double>(i);  // int → double
char c = static_cast<char>(65);      // int → char
```

#### 2.2 隐式转换的逆转换（向上转换）

cpp

```cpp
class Base {};
class Derived : public Base {};

Derived d;
Base* b = &d;                       // 隐式转换（向上转换）
Derived* d2 = static_cast<Derived*>(b);  // 反向转换（向下转换）
// ⚠️ 这里没有运行时检查！如果 b 实际上不是 Derived，是未定义行为
```

#### 2.3 类层次间转换（无多态）

cpp

```cpp
class A {};
class B : public A {};
class C : public A {};

B b;
A* a = &b;
// C* c = static_cast<C*>(a);  // ❌ 编译错误！A 到 C 的转换不明确
```

#### 2.4 转换到 `void*` 或从 `void*` 转换

cpp

```cpp
int x = 42;
void* v = static_cast<void*>(&x);
int* p = static_cast<int*>(v);  // 从 void* 转回来
```

### 3. **`dynamic_cast`：安全的向下转换（需要多态）**

**核心特点：** 运行时类型检查，转换失败返回 `nullptr`（指针）或抛异常（引用）。

#### 3.1 向下转换（基类→派生类）

cpp

```cpp
#include <typeinfo>

class Base {
public:
virtual ~Base() = default;  // ✅ 必须有虚函数！
};

class Derived : public Base {};

Base* base_ptr = new Derived();  // 指向派生类的基类指针

// 安全的向下转换
Derived* derived_ptr = dynamic_cast<Derived*>(base_ptr);
if (derived_ptr) {
// ✅ 转换成功，base_ptr 确实指向 Derived 对象
derived_ptr->doSomething();
} else {
// ❌ 转换失败，base_ptr 指向的不是 Derived
}

// 引用版本（失败时抛出 std::bad_cast）
Base& base_ref = *base_ptr;
try {
Derived& derived_ref = dynamic_cast<Derived&>(base_ref);
// 成功
} catch (const std::bad_cast& e) {
// 失败
}
```

#### 3.2 交叉转换（兄弟类之间）

cpp

```cpp
class Base { virtual ~Base() = default; };
class Derived1 : public Base {};
class Derived2 : public Base {};

Derived1 d1;
Base* base = &d1;

// 交叉转换
Derived2* d2 = dynamic_cast<Derived2*>(base);
// d2 == nullptr，因为 base 指向的是 Derived1，不是 Derived2
```

#### 3.3 使用限制

cpp

```cpp
class NotPolymorphic {};  // 没有虚函数

NotPolymorphic obj;
// NotPolymorphic* p = dynamic_cast<NotPolymorphic*>(&obj);
// ❌ 编译错误！dynamic_cast 要求类有多态（有虚函数）
```

### 4. **`const_cast`：移除或添加 const**

**⚠️ 极其危险！** 移除 `const` 后修改原本 const 的对象是未定义行为。

#### 4.1 移除 const

cpp

```cpp
void modifyValue(int* p) {
*p = 100;
}

const int x = 10;
// modifyValue(&x);  // ❌ 错误！不能将 const int* 转为 int*

int* p = const_cast<int*>(&x);  // ✅ 移除 const
*p = 200;  // ⚠️ 未定义行为！x 是 const，但被修改了

// 安全用法：移除 const 是为了调用只读函数
class MyClass {
public:
void readOnly() const { /* 不修改对象 */ }
};

const MyClass obj;
const_cast<MyClass&>(obj).readOnly();  // 移除 const 调用函数
```

#### 4.2 添加 const

cpp

```cpp
int y = 20;
const int* cp = const_cast<const int*>(&y);  // 添加 const
// *cp = 30;  // ❌ 错误！cp 是 const
```

#### 4.3 典型应用：C 风格 API

cpp

```cpp
// 某个 C 库函数声明：void process(char* str);
// 但我们只有 const char*

const char* text = "hello";
process(const_cast<char*>(text));  // 如果 process 会修改，危险！
```

### 5. **`reinterpret_cast`：危险的位重新解释**

**核心特点：** 几乎不做任何检查，只是把内存"重新解释"为另一种类型。**极度危险，使用需极度谨慎！**

#### 5.1 指针和整数之间的转换

cpp

```cpp
int x = 42;
uintptr_t address = reinterpret_cast<uintptr_t>(&x);  // 指针 → 整数
int* p = reinterpret_cast<int*>(address);  // 整数 → 指针
```

#### 5.2 不相关类型的指针转换

cpp

```cpp
struct A { int a; };
struct B { double b; };

A a;
B* b_ptr = reinterpret_cast<B*>(&a);  // ⚠️ 危险！A 和 B 无关
// b_ptr->b 会访问 A 的内存作为 double，未定义行为
```

#### 5.3 函数指针转换（某些系统需要）

cpp

```cpp
void func() {}

// 存储函数指针到 void*
void* v = reinterpret_cast<void*>(func);
void (*fp)() = reinterpret_cast<void(*)()>(v);
```

#### 5.4 标准用途：位操作

cpp

```cpp
// 查看 float 的二进制表示
float f = 3.14f;
uint32_t bits = reinterpret_cast<uint32_t&>(f);
std::cout << std::hex << bits;  // 输出浮点数的 IEEE 754 表示
```

### 6. **选择指南**

cpp

```cpp
// 场景1：基本类型转换、明确安全的转换
int i = 10;
double d = static_cast<double>(i);  // ✅ 使用 static_cast

// 场景2：多态类的安全向下转换
Base* base = new Derived();
Derived* derived = dynamic_cast<Derived*>(base);  // ✅ 使用 dynamic_cast

// 场景3：需要移除 const
const int* cp = &i;
int* p = const_cast<int*>(cp);  // 仅当确定原对象不是 const 时使用

// 场景4：低级别位操作
int* p = &i;
void* v = reinterpret_cast<void*>(p);  // ⚠️ 谨慎使用
```

### 7. **最佳实践**

| 转换操作符 | 何时使用 | 何时避免 |
| --- | --- | --- |
| **`static_cast`** | 绝大多数转换场景 | 多态类的向下转换（应使用 dynamic\_cast） |
| **`dynamic_cast`** | 基类到派生类（多态） | 性能敏感代码（RTTI 有开销） |
| **`const_cast`** | 调用不修改 const 对象的函数 | 修改原对象是 const 的内容 |
| **`reinterpret_cast`** | 系统级编程、序列化 | 几乎所有其他情况 |

### 8. **C 风格转换 vs C\+\+ 风格转换**

cpp

```cpp
// C 风格（不推荐）
double d = (double)10;        // 不明确是哪种转换
int* p = (int*)malloc(10);    // 不安全

// C++ 风格（推荐）
double d = static_cast<double>(10);  // 明确意图
int* p = static_cast<int*>(malloc(10));  // 更安全
```

**C\+\+ 风格的优势：**

1.
**意图明确**：一眼看出是什么类型的转换
2.
**易于搜索**：可以全局搜索 `static_cast` 等关键字
3.
**更安全**：编译时检查更多，`dynamic_cast` 有运行时检查

### 9. **完整示例：综合使用**

cpp

```cpp
#include <iostream>
#include <typeinfo>

class Animal {
public:
virtual ~Animal() = default;
virtual void speak() const { std::cout << "Animal\n"; }
};

class Dog : public Animal {
public:
void speak() const override { std::cout << "Woof!\n"; }
void fetch() { std::cout << "Fetching...\n"; }
};

class Cat : public Animal {
public:
void speak() const override { std::cout << "Meow!\n"; }
};

int main() {
// static_cast：基本类型
int i = 10;
double d = static_cast<double>(i);

// dynamic_cast：安全的向下转换
Animal* a = new Dog();
Dog* dog = dynamic_cast<Dog*>(a);
if (dog) {
dog->fetch();  // ✅ 安全调用
}

// const_cast：移除 const（仅用于调用不修改的函数）
const Animal& const_animal = *a;
// 假设有个函数：void doSomething(Animal& animal);
doSomething(const_cast<Animal&>(const_animal));

// reinterpret_cast：位解释（谨慎！）
int* ptr = &i;
void* vptr = reinterpret_cast<void*>(ptr);
int* p2 = reinterpret_cast<int*>(vptr);

delete a;
return 0;
}
```

### 核心总结

> **`static_cast`：常规转换，最常用**
> **`dynamic_cast`：安全的基类→派生类（需要虚函数）**
> **`const_cast`：移除 const（危险！仅当你确定）**
> **`reinterpret_cast`：位级别重新解释（极度危险！）**

**一句话规则：**

-
能用 `static_cast` 就先用它
-
多态向下转换用 `dynamic_cast`
-
别用 `const_cast` 和 `reinterpret_cast`，除非你知道自己在做什么
