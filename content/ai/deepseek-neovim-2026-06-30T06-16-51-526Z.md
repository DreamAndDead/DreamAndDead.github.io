## Assistant

在 Neovim 中，如果你说的“diss”是指**对比两个文件并查看它们之间的差异（diff）**，那么核心就是使用内置的 `:diff` 相关命令。这是进行代码审查、合并冲突解决等任务的常用方法。

以下是几种操作方式，可以按场景选择：

---

### 🖥️ 方式一：在已打开的窗口间进行 Diff

如果你已经用 `:split` 或 `:vsplit` 打开了两个文件，可以直接启用 diff 模式。

1.
**打开两个文件**（例如，左右分屏）：
vim

```vim
:vsplit file1.txt
:vsplit file2.txt
```
2.
**启用 Diff 模式**：将光标分别移动到两个窗口，执行命令 `:diffthis`。或者在所有需要对比的窗口中依次执行：
vim

```vim
:windo diffthis
```

### 📂 方式二：使用 `:diffsplit` 直接对比文件

你可以直接从命令行对比当前文件和另一个文件。

-
**水平对比**：`:diffsplit other_file.txt`，新文件会在水平分割窗口中打开并对比。
-
**垂直对比**（更常用）：`:vertical diffsplit other_file.txt`，新文件会在右侧垂直分割窗口中打开并对比。

### 🛠️ 方式三：使用 `vimdiff` 启动

在终端启动 Neovim 时，可以直接用 `vimdiff` 命令（或 `nvim -d`）对比两个文件，这是最快捷的方式。

bash

```bash
nvim -d file1.txt file2.txt
```

或

bash

```bash
vimdiff file1.txt file2.txt
```

### 🔄 如何退出 Diff 模式

在一个对比窗口中执行 `:diffoff` 即可退出该窗口的对比模式。要在所有窗口中关闭，可以执行 `:diffoff!`。

### 💡 高效 Diff 操作技巧

在 diff 模式下，常用的操作键位会变化，帮你快速处理差异：

| 操作 | 键位 | 说明 |
| --- | --- | --- |
| **跳转到下一个差异** | `]c` | 跳到下一个不同的块 |
| **跳转到上一个差异** | `[c` | 跳到上一个不同的块 |
| **将当前块从左侧应用至右侧** | `do` \(diff obtain\) | 将当前窗口的改动，应用到对侧窗口 |
| **将当前块从右侧拉取至左侧** | `dp` \(diff put\) | 拉取对侧窗口的改动到当前窗口 |
| **折叠/展开差异块** | `zo` / `zc` | 可以折叠或展开差异区域，便于总览 |

### 🎨 插件增强（可选）

如果你希望界面更直观，可以考虑安装一个增强插件，例如 **`diffview.nvim`**。它提供了一个更现代的文件差异视图，并集成了 Git 文件浏览等功能，用起来会更顺手。

总的来说，`vimdiff` 或 `nvim -d` 是最直接的启动方式，而 `:diffsplit` 和 `:diffthis` 则更灵活，适合在工作流中随时调用。
