# ReaScript 完整讲解（结合你**游戏音频 + Reaper + FMOD/C++ 自研项目**的用途）

## 一、什么是 ReaScript

**ReaScript 是 REAPER 内置的完整脚本编程接口**，是 REAPER 最强的特色，相当于给 REAPER 开了一套完整开放 API，可以用代码操控软件**所有功能**，把重复音频工作全自动完成REAPER。
 简单理解：
 REAPER 本体是手动操作的 DAW，**ReaScript 就是它的可编程后台**，能代码控制轨道、音频块、效果器、批量导出、标记、文件读写，甚至和 FMOD、Wwise、自研 C++ 程序做跨软件通信。

### 支持 3 种脚本语言

1. **Lua（最主流，游戏音频首选）**：语法简单、社区脚本最多，新手首选
2. **EEL2（REAPER 自研）**：运行速度最快，适合高性能实时处理
3. **Python（reapy 库）**：适合对接外部程序、读写 CSV、对接游戏工程文件

所有脚本直接在 REAPER 内运行，无需额外编译，写完即用。

## 二、核心本质：能调用 REAPER 全套底层 API

ReaScript 几乎可以操控 REAPER 里 100% 的手动操作：

- 新建 / 删除轨道、批量重命名轨道（游戏分层 BGM 必备）
- 裁剪音频块、自动修剪静音、批量音调偏移
- 批量加载 EQ / 压缩 / 降噪效果器链
- 自动添加 Marker 标记（循环点、剧情时间轴）
- **批量分轨渲染导出 WAV/OGG**（对接 FMOD 的核心）
- 读写本地文件、导出事件清单 CSV、与外部程序收发数据

## 三、在游戏音频开发里的核心用法（完全贴合你的工作流）

你的完整链路：**Reaper 编曲分轨 → ReaScript 自动化处理素材 → 导入 FMOD 做交互音乐 → C++ 游戏调用**，ReaScript 负责**提速前期素材生产**。

### 1. 交互式游戏 BGM 自动化（对接 FMOD 分层音乐）

做纵向分层 BGM（底层和弦、旋律、鼓、铜管多轨道）时，手动导出几十条分轨效率极低，脚本一键搞定：

1. 脚本自动识别所有轨道名称，**按轨道单独批量导出 WAV**，自动命名；
2. 自动对齐循环首尾波形，批量给所有 Loop 添加循环标记 Marker；
3. 自动筛选静音轨道，跳过空轨，避免导出无效文件。 导出的分轨文件直接丢进 FMOD 制作 Vertical 分层 Event，大幅减少手动操作。

### 2. 游戏音效 SFX 批量自动化处理（脚步声、技能音效）

游戏音效动辄几百上千条，是 ReaScript 的主战场：

1. **自动修剪头尾静音**：一键批量切除所有音频首尾空白，防止游戏触发音效延迟；
2. 批量随机音调、音量：一键生成多版脚步声采样，实现随机播放，避免重复听觉疲劳；
3. 批量标准化响度：统一所有音效音量，提前做 EQ 降噪，不用逐个手动调。

### 3. 剧情语音 VO 批量处理

1. 根据录音波形自动分割每一句台词，自动按序号命名；
2. 读取视频时间轴，自动生成字幕时间码 CSV 文件，直接对接游戏剧情程序；
3. 批量导出单条语音文件，适配 FMOD 语音总线分类。

### 4. 打通 Reaper ↔ FMOD/Wwise 工作流

专业游戏音频有成熟 ReaScript 脚本，可以双向联动：

1. 脚本读取 Reaper 轨道 / 标记，**自动生成 FMOD Event 路径对照表**，不用手动手打事件名；
2. 在 Reaper 时间线标记触发点位，同步对应 FMOD 的 RTPC 参数、切换状态，编曲阶段就能预览游戏音乐切换逻辑。

### 5. 批量格式压缩（成品游戏资源）

一键批量把 WAV 无损源码转 OGG 压缩格式，自定义码率：

- BGM：256kbps OGG
- 音效 / 人声：128kbps OGG 自动分类文件夹，完美适配游戏打包规范。

## 四、入门基础操作（快速上手）

1. 打开动作窗口：快捷键 `?`（问号键）
2. 新建脚本：New ReaScript，选择 Lua 语言，保存
3. 运行脚本：选中脚本 → Load/Run；常用脚本可以绑定快捷键、放到工具栏按钮一键点击
4. 海量免费脚本仓库：**ReaPack**（插件一键安装上千款现成游戏音频脚本，不用自己写代码）

## 五、极简 Lua 示例脚本（入门看懂逻辑）

### 示例 1：选中轨道，批量单独导出文件（游戏分轨最常用）

```lua
-- ReaScript Lua 简易分轨渲染
reaper.Main_OnCommand(41824, 0) -- 执行REAPER自带批量分轨渲染命令
reaper.ShowMessageBox("分轨导出完成！", "提示", 0)
```

几百行复杂功能的脚本，社区都有现成成品，直接加载使用。

### 示例 2：一键把所有带`BGM`字样的轨道静音

```lua
track_count = reaper.CountTracks(0)
for i = 0, track_count-1 do
    track = reaper.GetTrack(0, i)
    _, name = reaper.GetTrackName(track)
    if string.find(name, "BGM") then
        reaper.SetMediaTrackInfo_Value(track, "B_MUTE", 1)
    end
end
```

## 六、和 FMOD 的分工边界（不要混淆）

1. **Reaper + ReaScript = 静态素材生产端** 只做音频的编曲、剪辑、批量导出，输出固定的音频文件，**不能在游戏运行时动态切换声部、实时 RTPC 参数、3D 空间混音**。
2. **FMOD / SoLoud = 游戏运行时 Runtime** 读取导出好的音频素材，实现玩家游戏过程中的动态音乐交互、3D 音效、总线混音。

## 七、开源低成本配套方案（适配你的原生 C++ 项目）

不想付费 FMOD，完整免费工作流：
`Reaper + ReaScript（自动化制轨）` + `SoLoud（开源C++音频Runtime）`
 ReaScript 批量输出分层音轨，C++ 代码用 SoLoud 加载多轨音频，手动写参数控制逻辑，完全开源免费，适合自研引擎。

## 八、新手必装资源

1. **ReaPack**：脚本管理器，一键安装全网开源 ReaScript 合集，内置大量游戏音频专用脚本；
2. nvk_WORKFLOW：专业游戏音频专用脚本套件，专门针对音效、分层配乐、对接音频中间件优化。
