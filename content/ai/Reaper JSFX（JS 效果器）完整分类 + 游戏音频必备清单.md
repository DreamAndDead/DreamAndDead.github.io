# Reaper JSFX（JS 效果器）完整分类 + 游戏音频必备清单

JSFX（Jesusonic）是 Reaper 原生脚本效果器，**完全免费、无版权、轻量省 CPU、可直接查看源码修改**，分为**官方内置自带 JS** + **社区第三方 JS（ReaPack 一键安装）**两大类，下面按游戏音频的实际用途分类讲解，完全贴合你做**分层 BGM、游戏音效 SFX、配音 VO、对接 FMOD**的工作流。

## 一、官方原生自带核心 JSFX（安装 Reaper 即自带，无需额外下载）

### 1. 均衡滤波类（游戏混音刚需，修频段、防频段打架）

1. **ReaFir（全能王牌 JS）** 五合一多功能：自定义绘图 EQ、降噪、门限、压缩、卷积混响，游戏音频头号神器。
   - 用途：精准切除音效低频浑浊、刺耳高频；录制人声底噪消除；自定义滤波器做水下闷音、山洞滤波效果。
2. **JS: Filters 系列**
   - Lowpass/Highpass：高低通滤波，快速做闷声、电话音、远场环境音；
   - Parametric EQ：参数均衡，精细调节 BGM 分轨频段，避免旋律轨和鼓轨频段重叠；
   - DC Remove：直流偏移消除，修复录音爆底噪，批量处理语音必备。

### 2. 动态压缩 / 门限类（统一音量、防爆音、自动静音）

1. **ReaComp** 侧链压缩之王 支持**任意侧链输入**，完美复刻 FMOD 的**人声闪避**逻辑：语音轨作为侧链，自动压低背景音乐音量，游戏剧情对白混音标配。
2. **ReaGate 噪声门** 自动切除音频首尾静音，批量脚步声、环境音一键自动修剪空白，解决游戏音效触发延迟问题。
3. **ReaXComp 多段压缩** 分频段动态控制，用来批量统一所有游戏音效响度，导出后放进 FMOD 总线混音更稳定。

### 3. 混响 / 延迟空间类（提前预制环境音效）

1. **ReaVerb 卷积混响** 可加载 IR 采样脉冲，一键做出大厅、山洞、隧道、室外旷野混响；可以前期预制，也可以留给 FMOD 运行时实时 3D 混响。
2. **JS: Delay 延迟合集** 标准延迟、合唱 Chorus、镶边 Flanger、相位 Phaser，专门做魔法、技能、科幻电子音效；`delay_varlen`可变延迟适合做武器嗡鸣、风声。

### 4. 音调变速类（批量生成音效变体）

路径：`JS: Pitch`

- `pitchdown/pitchup`：半音精细移调；`octaveup/octavedown`八度升降；
- **游戏核心用法**：同一段脚步声，批量 ±2~5 音高生成多份采样，导入 FMOD 随机播放，避免脚步声重复听觉疲劳。

### 5. 失真 / 塑形音效类（武器、打击、怪物嘶吼）

路径：`JS: Guitar`
 失真 Distortion、Fuzz 法兹、哇音 Wah，用来做厚重近战打击、怪物咆哮、爆炸失真基底音效。

### 6. 工具工具类 Utility

- 相位反转、声道互换、立体声转单声道（手游音频强制单声道适配）；
- 音量标准化、峰值限制器，防止导出 WAV 波形削波爆音。

## 二、第三方社区热门 JSFX（ReaPack 一键安装，游戏音频专用）

安装方式：先装 ReaPack 插件管理器，一键导入插件仓库，海量免费 JS。

### 1. 音效合成 SFX 专用（从零生成游戏特效音）

1. **ReaWhoosh** 专门生成**划过、瞬移、冲刺、飞掠 Whoosh 呼啸音效**，动作游戏必备，可视化参数调节起止音调、包络、噪声厚度。
2. **Bit Crusher 位深破碎机** 降采样、低比特失真，制作复古像素游戏音效、对讲机音效、电子故障音效。
3. **Seed Delay 多抽头随机延迟** 自然随机延迟算法，制作环境氛围音、魔法余音、洞穴回声，效果远超普通延迟插件。

### 2. 动态压缩硬件模拟（对标付费商业插件）

**mawi 经典硬件模拟套件**（热门免费）

- FET76（1176）：鼓组、打击音效压缩，力度紧实；
- Opto23（LA-2A）：人声、弦乐 BGM 温柔压缩；
- SSL 总线压缩：整轨 BGM 总线粘合，分层配乐混音更融合。

### 3. 降噪与修复（配音、实地录音处理）

1. **Tukan Denoiser** 智能 AI 降噪 比 ReaFir 降噪更智能，处理室外配音、环境录音底噪，保留人声细节。
2. **ReaNoise 自适应降噪** 低成本批量语音降噪，适合大量 NPC 对白素材处理。

### 4. 批量自动化工作流 JS（配合 ReaScript，对接 FMOD）

1. **Render Blocks** 按轨道文件夹自动命名、分轨批量导出，轨道名直接生成 FMOD Event 路径命名规则，完美适配分层 BGM 批量导出流程。
2. **Auto Trim Items** 一键批量修剪所有音频首尾静音，几百条脚步声、技能音效全自动处理。

## 三、结合你的工作流：JSFX 在「Reaper→FMOD→C++ 游戏」的完整用法

1. **分层游戏 BGM 制作** Reaper 分轨编曲 → 用**ReaEQ/ReaComp**做轨道频段平衡、音量压缩 → JS 移调微调声部音色 → ReaScript 批量导出分轨 WAV → 导入 FMOD 做纵向分层 Event。
2. **游戏音效批量制作** 原始采样 + BitCrusher / 失真 / ReaWhoosh 塑形 → ReaGate 自动修静音 → 批量移调生成多变体采样 → FMOD 设置随机播放。
3. **剧情人声处理** 录音用 Tukan 降噪 → ReaComp + 侧链闪避预设 → 标准化响度导出 → FMOD 语音总线管理，游戏运行时自动压低 BGM。
4. **注意区分边界** JSFX 只做**前期素材静态处理**；3D 空间动态混响、RTPC 参数、运行时实时闪避，交给 FMOD/SoLoud Runtime 实现。

### 必装自带 JS（默认就有）

ReaFir、ReaComp、ReaGate、ReaVerb、JS Pitch 移调、JS 高低通滤波

### ReaPack 必装第三方

ReaWhoosh、mawi 压缩套件、Tukan 降噪、Render Blocks 批量导出工具

## 五、JSFX 核心优势（对比 VST 商业插件）

1. **零成本商用**：全部开源免费，无版权授权费用，独立游戏、自研商用项目随便用；
2. **性能极轻**：EEL 脚本编写，CPU 占用极低，老旧电脑也能批量处理上千音效；
3. **可二次修改**：可以打开 JS 源码修改算法，甚至自己改写脚本适配专属游戏音频流程；
4. **跨平台通用**：Windows/macOS/Linux 全部通用，工程移植不会丢失插件。
