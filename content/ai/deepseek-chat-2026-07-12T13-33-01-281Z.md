## Assistant

在2D游戏中判断人物碰到墙壁的哪一面，核心思路不是去“读取墙的属性”，而是**通过分析碰撞发生时的位移方向（或速度方向）**来反推。

这里有三种主流实现方案，按推荐程度从高到低排列：

### 方案一：基于“最小穿透轴”判断（最推荐）

这是目前最通用的做法。当人物与墙体重叠时，**哪个轴向上穿透的深度浅，就说明是从哪个方向撞上去的**。

**具体逻辑（以轴对齐矩形为例）：**

1.
人物移动后，检测到与墙壁发生重叠。
2.
计算水平和垂直两个方向的**穿透深度**：

-
**水平穿透**：人物右边缘 - 墙壁左边缘（向右撞），或 墙壁右边缘 - 人物左边缘（向左撞）。
-
**垂直穿透**：人物下边缘 - 墙壁上边缘（向下撞），或 墙壁上边缘 - 人物下边缘（向上撞）。
3.
**比较绝对值**：取`水平穿透`和`垂直穿透`中**绝对值较小**的那个。

-
如果水平穿透更小 $\to$ **左面或右面**。
-
如果垂直穿透更小 $\to$ **上面或下面**。
4.
**确定正负**：根据穿透值的正负确定具体方向（正为右/下，负为左/上）。

> **优点**：解决了人物斜着撞墙时的“卡角”问题，物理感最自然。

---

### 方案二：基于“上一帧位置”对比（最简单）

不分析重叠本身，而是看人物**移动前和移动后**的位置变化。

**具体逻辑：**

1.
记录人物移动前的坐标 `(oldX, oldY)`。
2.
人物尝试移动，如果发生了碰撞：

-
比较 `newX` 和 `oldX`：

-
如果 `newX > oldX`（向右走）$\to$ 撞到的是**左面**（因为你在左边，向右走才撞到墙的左侧）。
-
如果 `newX < oldX`（向左走）$\to$ 撞到的是**右面**。
-
比较 `newY` 和 `oldY`：

-
如果 `newY > oldY`（向下走）$\to$ 撞到的是**上面**。
-
如果 `newY < oldY`（向上走）$\to$ 撞到的是**下面**。

> **注意**：这个方案要求你**分别检测X轴和Y轴移动**（先水平移动并修正，再垂直移动并修正）。如果同时移动再检测，斜着撞墙角时方向会误判。

---

### 方案三：计算“中心点夹角”（用于圆弧/不规则形状）

通过人物中心与墙壁中心（或碰撞点）的连线角度来判断。

**具体逻辑：**

1.
获取碰撞点的坐标 `(hitX, hitY)`。
2.
计算从人物中心指向碰撞点的向量角度：`atan2(hitY - playerY, hitX - playerX)`。
3.
根据角度区间判断：

-
`-45° ~ 45°` $\to$ **右面**
-
`45° ~ 135°` $\to$ **下面**
-
`135° ~ 180°` 或 `-180° ~ -135°` $\to$ **左面**
-
`-135° ~ -45°` $\to$ **上面**

> **缺点**：对于矩形墙壁，在墙角附近容易误判（比如碰到墙角外侧却判定为正面）。

---

### 实战代码示例（方案二改进版）

如果你用的是 Unity（C\#）或类似引擎，标准写法如下（核心是**分开移动**）：

csharp

```csharp
// 1. 先尝试水平移动
transform.position += new Vector3(moveX * Time.deltaTime, 0, 0);
if (检测到碰撞)
{
if (moveX > 0) 触碰左面();
else if (moveX < 0) 触碰右面();
// 回退位置
transform.position -= new Vector3(moveX * Time.deltaTime, 0, 0);
}

// 2. 再尝试垂直移动（单独处理）
transform.position += new Vector3(0, moveY * Time.deltaTime, 0);
if (检测到碰撞)
{
if (moveY > 0) 触碰上面();
else if (moveY < 0) 触碰下面();
// 回退位置
transform.position -= new Vector3(0, moveY * Time.deltaTime, 0);
}
```

### 特殊场景提醒

-
**如果人物卡在墙里了**：上述逻辑会失效。你需要在移动前**先修正位置**（把人物“推”出墙壁），再根据推离的方向判断。
-
**如果你只想显示“蹭墙”特效**：方案一最合适。
-
**如果墙体是斜的（45度）**：方案一和方案二都会失效，这时需要计算**碰撞法线**（碰撞点的垂直方向），用点积判断方向。
