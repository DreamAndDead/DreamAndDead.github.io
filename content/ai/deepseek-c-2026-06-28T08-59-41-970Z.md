## C\+\+ 虚函数的特点

虚函数是 C\+\+ 实现**多态**（Polymorphism）的核心机制。以下是它的主要特点：

---

### 1. **运行时绑定（动态绑定）**

虚函数的调用在**运行时**才确定，而不是编译时。

cpp

```cpp
class Base {
public:
virtual void show() { std::cout << "Base\n"; }
};

class Derived : public Base {
public:
void show() override { std::cout << "Derived\n"; }
};

Base* ptr = new Derived();
ptr->show();  // 输出 "Derived"（运行时决定）
```

---

### 2. **通过指针或引用调用才有多态效果**

只有通过**基类指针**或**基类引用**调用虚函数时，才会触发动态绑定。

cpp

```cpp
Derived d;
Base& ref = d;
ref.show();   // 输出 "Derived"（多态）

Base obj = d; // 对象切片（Object Slicing）
obj.show();   // 输出 "Base"（没有多态）
```

---

### 3. **虚函数表（vtable）机制**

每个包含虚函数的类都有一个**虚函数表**（vtable），存储所有虚函数的地址。每个对象有一个**虚指针（vptr）**指向该表。

-
**内存开销**：每个对象多一个指针大小（8字节/64位系统）。
-
**性能开销**：每次调用虚函数需要一次间接寻址（通过 vptr → vtable → 函数地址）。

---

### 4. **可以被子类重写（Override）**

派生类可以重写基类的虚函数，实现自己的行为。

cpp

```cpp
class Shape {
public:
virtual double area() const { return 0; }
};

class Circle : public Shape {
public:
double area() const override { return 3.14 * r * r; }
private:
double r = 5.0;
};
```

---

### 5. **支持纯虚函数（抽象类）**

用 `= 0` 声明纯虚函数，使类成为**抽象类**，不能实例化。

cpp

```cpp
class Animal {
public:
virtual void speak() = 0;  // 纯虚函数
};

class Dog : public Animal {
public:
void speak() override { std::cout << "Woof!\n"; }
};

// Animal a;  // ❌ 错误！不能实例化抽象类
Dog d;        // ✅ 必须实现所有纯虚函数
```

---

### 6. **基类必须定义虚析构函数**

这是**最重要的规则**！如果类会被继承，析构函数必须声明为 `virtual`，否则删除派生类对象时会导致**资源泄漏**。

cpp

```cpp
class Base {
public:
virtual ~Base() { }  // ✅ 必须 virtual
};

class Derived : public Base {
public:
~Derived() { }  // 自动成为虚函数
};

Base* p = new Derived();
delete p;  // 先调用 Derived 析构，再调用 Base 析构
```

如果析构函数不是虚函数，`delete p` 只会调用 `Base` 的析构函数，`Derived` 的资源不会被释放。

---

### 7. **构造函数不能是虚函数**

-
构造时对象还没完全创建，vptr 还没初始化。
-
虚函数表是在构造完成后才建立的。

---

### 8. **静态函数不能是虚函数**

静态函数属于类本身，不依赖对象，无法实现多态。

---

### 9. **可以使用 `override` 和 `final` 关键字（C\+\+11）**

-
**`override`**：明确表示重写基类虚函数，如果签名不匹配会报错。
-
**`final`**：禁止子类继续重写该虚函数。

cpp

```cpp
class Base {
virtual void func() { }
};

class Derived : public Base {
void func() override { }  // ✅ 明确重写
};

class FinalDerived : public Derived {
void func() final { }     // ✅ 最终版本，不能再重写
};
```

---

### 10. **支持协变返回类型**

派生类重写虚函数时，可以返回**更具体的类型**（基类返回类型的派生类）。

cpp

```cpp
class Base {
virtual Base* clone() const { return new Base(*this); }
};

class Derived : public Base {
Derived* clone() const override {  // ✅ 返回类型是 Base* 的派生类
return new Derived(*this);
}
};
```

## 总结表格

| 特点 | 说明 |
| --- | --- |
| **绑定时机** | 运行时绑定（动态多态） |
| **调用方式** | 必须通过指针或引用 |
| **内存开销** | 每个对象多一个虚指针（vptr） |
| **性能** | 比普通函数调用慢（间接寻址） |
| **必须虚的情况** | 析构函数（防止资源泄漏） |
| **不能虚的情况** | 构造函数、静态函数 |
| **纯虚函数** | 使类成为抽象类，不能实例化 |
| **C\+\+11 增强** | `override`、`final` 关键字 |

---

### 经典面试问题：**虚函数和普通函数的区别？**

|  | 普通函数 | 虚函数 |
| --- | --- | --- |
| **绑定** | 编译时（静态绑定） | 运行时（动态绑定） |
| **调用开销** | 直接跳转 | 通过 vtable 间接跳转 |
| **是否支持多态** | ❌ | ✅ |
| **内联优化** | 可能内联 | 通常不能内联（通过指针调用时） |
