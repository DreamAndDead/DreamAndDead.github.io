## User

如何遍历一个数组？

## Assistant

遍历数组有多种方式，现代C\+\+推荐使用**范围for循环**（range-based for loop）。

### ✅ 最推荐的方式：范围for循环 \(C\+\+11\)

这是最简洁、最安全、也是最现代C\+\+的写法，不需要手动处理索引或迭代器边界。

cpp

```cpp
int arr[] = {1, 2, 3, 4, 5};

// 1. 如果只想读取，用 const auto& (避免拷贝)
for (const auto& value : arr) {
std::cout << value << " ";
}

// 2. 如果需要修改数组元素，用 auto&
for (auto& value : arr) {
value *= 2; // 每个元素乘以2
}

// 3. 如果元素类型是 int 这样的小类型，直接用 auto 也可以
for (auto value : arr) {
std::cout << value << " ";
}
```

### 🔢 传统方式：索引循环

如果你需要知道当前元素的位置（索引），用这种最直接。

cpp

```cpp
int arr[] = {1, 2, 3, 4, 5};

// 方式1：使用 sizeof 计算数组长度 (C 风格)
for (size_t i = 0; i < sizeof(arr) / sizeof(arr[0]); ++i) {
std::cout << arr[i] << " ";
}

// 方式2：使用 std::size (C++17) 更安全简洁
for (size_t i = 0; i < std::size(arr); ++i) {
std::cout << arr[i] << " ";
}
```

### 🎯 使用标准库算法 \(STL\)

使用 `std::for_each` 配合 lambda 表达式，风格更函数式，在复杂的处理逻辑中代码意图会更清晰。

cpp

```cpp
#include <algorithm>

std::for_each(std::begin(arr), std::end(arr), [](int value) {
std::cout << value << " ";
});
```

### ⚠️ C 风格指针遍历 \(不推荐\)

这种写法容易出错，而且不够直观，仅当你需要兼容老式 C 代码或处理底层内存时才考虑。

cpp

```cpp
int* ptr = arr;
int* end = arr + sizeof(arr) / sizeof(arr[0]);
while (ptr < end) {
std::cout << *ptr++ << " ";
}
```

---

### 💎 总结与建议

| 场景 | 推荐写法 |
| --- | --- |
| **不修改元素** | `for (const auto& v : arr)` |
| **修改元素** | `for (auto& v : arr)` |
| **需要元素索引** | `for (size_t i = 0; i < std::size(arr); ++i)` |
| **对容器进行复杂操作** | `std::for_each` 等 STL 算法 |

如果数组很大，`const auto&` 能避免拷贝；如果元素类型是基础类型（如 `int`、`char`），直接 `auto` 也可以，因为拷贝开销很小。此外，`std::array` 和 `std::vector` 同样支持这些遍历方式，所以掌握这套写法后可以通用于各种容器。
