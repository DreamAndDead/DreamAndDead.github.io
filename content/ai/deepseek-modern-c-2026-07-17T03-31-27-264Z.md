## 数字取模和位运算 `&` 的关系

**核心结论：** `x % 2^n` 等价于 `x & (2^n - 1)`，即**取模 `2^n`**（2 的幂）**可以替代为按位与运算**。

---

### 1. **基本原理**

当除数是 2 的幂（如 2、4、8、16...）时，取模运算可以转化为位运算：

cpp

```cpp
x % 2^n  ==  x & (2^n - 1)
```

| 取模 | 等价位运算 | 说明 |
| --- | --- | --- |
| `x % 2` | `x & 1` | 判断奇偶 |
| `x % 4` | `x & 3` | 取低 2 位 |
| `x % 8` | `x & 7` | 取低 3 位 |
| `x % 16` | `x & 15` | 取低 4 位 |
| `x % 32` | `x & 31` | 取低 5 位 |

**为什么成立？**

-
二进制中，`2^n` 是 `1` 后面跟 `n` 个 `0`
-
一个数除以 `2^n` 的余数，就是它的**低 n 位**
-
`(2^n - 1)` 正好是 `n` 个 `1`（如 `7 = 0b111`）
-
`x & (2^n - 1)` 提取的就是低 n 位

**示例：**

cpp

```cpp
// 23 % 8 = 7
// 23 的二进制：10111
// 7 的二进制：  111
// 23 & 7 = 10111 & 00111 = 00111 = 7 ✅

// 示例代码
int x = 23;
int result_mod = x % 8;   // 7
int result_and = x & 7;   // 7
```

---

### 2. **为什么这样替代？性能优势**

-
**取模（`%`）**：除法指令，通常是 CPU 最慢的指令之一（几十个时钟周期）
-
**按位与（`&`）**：单个 CPU 周期，几乎是瞬间完成

在性能敏感场景（如循环、哈希表、内存池）中，位运算可以带来显著的性能提升。

---

### 3. **适用场景示例**

#### 场景 1：判断奇偶

cpp

```cpp
// ❌ 除法（慢）
if (x % 2 == 0) { /* 偶数 */ }

// ✅ 位运算（快）
if ((x & 1) == 0) { /* 偶数 */ }
```

#### 场景 2：环形缓冲区（Ring Buffer）

cpp

```cpp
constexpr size_t BUFFER_SIZE = 16;  // 2 的幂
size_t head = 0;

// 每次移动后取模
head = (head + 1) & (BUFFER_SIZE - 1);  // 等价于 head % 16
```

#### 场景 3：哈希表的桶索引

cpp

```cpp
// 保证桶的数量是 2 的幂，用 & 替代 %
size_t bucket_count = 1024;  // 2^10
size_t index = hash_value & (bucket_count - 1);
```

#### 场景 4：内存对齐

cpp

```cpp
// 向上对齐到 8 字节的倍数
size_t align_8 = (size + 7) & ~7;  // 等价于 (size + 7) / 8 * 8
// 也可以写作 (size + 7) & -8 (在二进制补码中)
```

---

### 4. **限制：只适用于 2 的幂**

| 除数 | 是否能用 `&` | 原因 |
| --- | --- | --- |
| `% 2` | ✅ | 2 是 2 的幂 |
| `% 3` | ❌ | 3 不是 2 的幂 |
| `% 4` | ✅ | 4 是 2 的幂 |
| `% 7` | ❌ | 7 不是 2 的幂 |
| `% 8` | ✅ | 8 是 2 的幂 |
| `% 10` | ❌ | 10 不是 2 的幂 |

cpp

```cpp
int x = 23;
int result1 = x % 3;   // 2
int result2 = x & 2;   // 2 ❌ 错误！只是巧合，结果不同
```

---

### 5. **负数的情况**

C\+\+ 中，负数取模的行为是**向零取整**（C\+\+11 起），但按位与对负数的影响需要特别注意：

cpp

```cpp
int x = -23;
int result_mod = x % 8;   // -7（向零取整）
int result_and = x & 7;   // -23 & 7 = 1（补码表示不同）

// ❌ 对负数不成立！
```

**如果需要对负数取模**，可以用 `(x % N + N) % N` 或使用无符号数。

---

### 6. **核心总结**

| 特性 | 说明 |
| --- | --- |
| **等价条件** | `x % 2^n == x & (2^n - 1)` |
| **仅适用于 2 的幂** | 非 2 的幂不能用位运算替换 |
| **性能优势** | `&` 远快于 `%`（单周期 vs 几十周期） |
| **适用范围** | 环形缓冲区、哈希表、内存对齐、判断奇偶 |
| **负数** | 位运算适用于补码表示，不能简单替换负数的取模 |

### 核心记忆

> **取模 2 的幂，等于按位与（2^n - 1）**
> **位运算快，除法慢，性能场景优先用 `&`**
> **但只适用于正数，且除数必须为 2 的幂**
