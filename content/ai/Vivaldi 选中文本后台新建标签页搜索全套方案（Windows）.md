# Vivaldi 选中文本**后台新建标签页搜索**全套方案（Windows）

分为**原生自带功能（零扩展，首选）**、**自定义快捷键**、**鼠标手势**、**扩展增强**四种方式，按顺手程度排序。

## 一、原生最省事：右键菜单 + 全局标签后台设置（无需插件）

Vivaldi 原生自带选中文本搜索，只要提前开启「新标签默认后台打开」，右键搜索就会自动在后台新建标签，不会切走当前页面。

### 1. 全局设置新链接默认后台打开

1. 打开设置：`vivaldi://settings/tabs/`
2. 找到 **从链接打开的新标签页**，勾选：**在后台打开**
3. 顺带开启：**始终在新标签页执行搜索**（设置 → 搜索）

### 2. 使用方法

1. 选中任意网页文字
2. 右键 → **搜索【选中文字】** 执行后，搜索页面会**静默在后台生成新标签**，你留在原页面不动，完美实现后台搜索。

### 补充：右键临时前台 / 后台切换

- 普通点击右键搜索：遵循上面全局设置（后台）
- 按住 `Shift` 点击右键搜索：强制前台激活新标签

## 二、自定义专属快捷键（键盘党最优）

可以绑定快捷键，**选中文本一键后台搜索**，不用点开右键菜单。

1. 进入快捷键设置：`vivaldi://settings/keyboard/`
2. 筛选命令：搜索关键词 `Search Selection`
   - `Search Selection in New Background Tab`：**选中内容在后台新标签搜索**（核心命令）
   - `Search Selection in New Tab`：前台新标签搜索
3. 点编辑，绑定你习惯的组合键，例：`Alt+S`、`Ctrl+Shift+F`。

使用流程：选中文字 → 按下快捷键，瞬间后台生成搜索标签。

## 三、鼠标手势（老手经典方案，继承 Opera 习惯）

适合全程手不离鼠标，划手势完成后台搜索：

1. 设置 → **鼠标 → 鼠标手势**，开启「启用鼠标手势」
2. 点「编辑手势」，在网页动作里找到：**搜索所选内容（后台新标签）**，自定义手势轨迹（比如：**右→下**）。
3. 使用：选中文字后，按住右键划出设定手势，直接后台搜索。

## 四、进阶方案：第三方扩展（多引擎、拖拽搜索）

原生只能用默认搜索引擎，需要一键切换百度 / 必应 / 豆包搜索，安装 Chrome 内核通用扩展，Vivaldi 完美兼容：

### 推荐扩展：Selection Search

1. 应用商店安装后，右键选中文字会弹出多搜索引擎菜单
2. 扩展设置内可以勾选：**搜索结果在后台标签打开**
3. 额外功能：**拖拽文字直接搜索**，选中文字拖动一小段距离，即可弹出搜索引擎，松手后台打开结果。

## 五、避坑常见问题

1. **右键搜索依旧前台跳转** 检查标签设置：确认开启「从链接打开的新标签页 在后台打开」，同时关闭强制前台的手势 / 快捷键。
2. **快捷键找不到后台搜索命令** 更新 Vivaldi 到最新稳定版，旧版本只提供前台搜索命令。
3. **右键菜单没有「搜索选中文字」** 设置 → 外观 → 菜单自定义，在网页右键菜单里，把「搜索所选内容」拖入右键菜单即可。

## 最简最终推荐搭配

1. 普通日常使用：**全局标签后台设置 + 原生右键搜索**，零插件最稳定；
2. 键盘高频使用：绑定 `Alt+S` 作为后台搜索快捷键；
3. 多引擎切换需求：加装 Selection Search 扩展。
