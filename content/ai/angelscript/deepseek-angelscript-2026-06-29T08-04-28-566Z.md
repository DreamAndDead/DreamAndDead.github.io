@  的含义

## Assistant

在 AngelScript 中，`@` 符号承载了两个核心且不同的含义，理解它们对正确使用这门语言至关重要。它既是一个**声明符**，用于定义特殊的变量类型，也是一个**操作符**，用于执行特定的赋值操作。

### 含义一：声明对象句柄 \(Object Handle\)

当 `@` 出现在变量声明中时，它表示这个变量是一个**对象句柄**，而不是一个对象实例。这类似于 C\+\+ 中的指针或引用。

-
**语法**：`类型 @变量名;`
-
**核心作用**：句柄用于**引用**（指向）一个已存在的对象，而不是存储对象本身。它不会在声明时自动创建对象，默认值为 `null`。
-
**使用场景**：这是使用引用类型（用 `asOBJ_REF` 注册的 C\+\+ 类，或脚本中定义的类）的标准方式。

angelscript

```angelscript
// 声明一个句柄，初始为 null
MyClass@ obj;

// 创建一个对象实例，并将句柄指向它
@obj = MyClass(); // 注意这里的 @ 是操作符，见下文

// 或者让句柄指向另一个已存在的对象
MyClass@ another = obj;
```

### 含义二：赋值操作符中的引用传递

当 `@` 符号出现在赋值操作符（`=`）的左侧时，它的作用是**执行句柄赋值**，即让左侧的句柄指向右侧的对象，而**不会**复制或创建新对象。

-
**语法**：`@变量 = 表达式;`
-
**核心作用**：区分“值赋值”和“引用赋值”。这对于值类型（`asOBJ_VALUE`）尤其重要，因为默认的 `=` 会进行值拷贝。
-
**使用场景**：当你需要让一个句柄指向一个新对象，或改变一个句柄的指向时。

angelscript

```angelscript
MyClass@ obj;

// 1. 使用 @ 进行引用赋值：创建一个对象，obj 指向它
@obj = MyClass();

// 2. 没有 @ 的值赋值：这是错误的，因为 obj 是一个句柄变量
//    obj = MyClass(); // 编译错误！
```

### 完整示例：声明、赋值与使用

为了更清晰地展示，我们看一个完整的例子：

angelscript

```angelscript
class Actor {
void SayHello() { print("Hello!"); }
}

void main() {
// 1. 声明一个句柄，此时为 null
Actor@ actor;

// 2. 使用 @ 操作符进行引用赋值，创建对象并让句柄指向它
@actor = Actor();

// 3. 使用句柄调用对象的方法
actor.SayHello();

// 4. 声明另一个句柄并指向同一个对象
Actor@ another = actor;

// 5. 将 actor 置空，对象仍然被 another 引用，不会被销毁
@actor = null;

// 6. 使用 another 仍然可以访问对象
another.SayHello();
}
```

### 核心区别速查表

| 特征 | `类型 变量` \(值类型\) | `类型@ 句柄` \(引用类型\) |
| --- | --- | --- |
| **存储方式** | 在栈上存储对象本身 | 在栈上存储对象地址（指针） |
| **默认值** | 调用默认构造函数 | `null` |
| **赋值 `a = b`** | 拷贝 `b` 的值到 `a` | 让 `a` 指向 `b` 引用的同一对象 |
| **引用赋值 `@a = b`** | ❌ 不适用（除非注册了 `opAssign`） | 让 `a` 指向 `b` 引用的同一对象 |
| **生命周期** | 作用域结束时自动销毁 | 引用计数管理，计数为0时销毁 |

### 💡 常见误区

-
**`@` 不是取地址符**：它不像 C\+\+ 中的 `&` 那样取变量的内存地址，而是专门用于 AngelScript 的句柄管理。
-
**句柄不是指针**：AngelScript 的句柄是类型安全的，你不能像 C\+\+ 指针那样进行算术运算（`ptr++`），也不能随意转换类型。
-
**区分声明与赋值**：声明时的 `类型@ 变量` 和赋值时的 `@变量 = ...` 是两个不同的语法元素，它们的 `@` 位置不同，含义也不同。

### 💎 总结

`@` 在 AngelScript 中承担了两个角色：

1.
**在声明中**（`类型@ 变量`）：表示这是一个引用类型的**句柄**。
2.
**在赋值中**（`@变量 = 值`）：表示执行的是**引用赋值**，而不是值拷贝。

记住：**AngelScript 中的 `@` 是专门为句柄系统设计的，它既不是取地址符，也不是指针运算符，而是这门语言管理对象生命周期的核心工具。** 它与 C\+\+ 的指针在概念上相似，但使用方式和安全级别都不同。
