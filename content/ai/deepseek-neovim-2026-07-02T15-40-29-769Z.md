## User

mksession vs mkview

## Assistant

`mksession` 和 `mkview` 是 Neovim 中两个用于保存状态的内置命令，但它们的**作用范围**和**使用场景**截然不同。

### 🎯 核心区别

| 特性 | `:mksession` | `:mkview` |
| --- | --- | --- |
| **作用范围** | **整个 Neovim 会话**（所有窗口、标签页、布局） | **单个窗口/缓冲区**（当前文件的状态） |
| **保存内容** | 窗口布局、标签页、文件列表、全局设置、映射 | 光标位置、折叠状态、滚动位置、局部选项 |
| **恢复方式** | `:source Session.vim` | 打开文件时自动加载（或 `:loadview`） |
| **适用场景** | 恢复一个完整的开发环境 | 在单个文件中延续上次编辑的状态 |
| **文件位置** | 当前目录下的 `Session.vim` | `~/.local/state/nvim/view/` 目录 |

---

### 📂 `:mksession`：保存整个工作区

`:mksession` 会生成一个 `Session.vim` 文件，里面记录了当前 Neovim 会话的完整状态。适合在项目结束时保存环境，下次直接恢复。

vim

```vim
:mksession              " 保存到当前目录的 Session.vim
:mksession ~/my.session " 保存到指定路径
```

恢复时：

vim

```vim
:source Session.vim
```

你可以在 `init.lua` 中配置自动保存和加载：

lua

```lua
-- 自动保存会话
vim.api.nvim_create_autocmd("VimLeave", {
callback = function()
vim.cmd("mksession! ~/session.vim")
end,
})

-- 自动加载会话
vim.api.nvim_create_autocmd("VimEnter", {
callback = function()
vim.cmd("source ~/session.vim")
end,
})
```

---

### 📄 `:mkview`：保存单个文件状态

`:mkview` 只记录当前窗口的局部状态。它不会保存其他窗口或标签页的信息。

vim

```vim
:mkview    " 保存当前窗口的视图
:loadview  " 加载视图
```

配置自动保存和加载：

lua

```lua
vim.api.nvim_create_autocmd("BufWinLeave", {
pattern = "*",
callback = function()
vim.cmd("mkview")
end,
})

vim.api.nvim_create_autocmd("BufWinEnter", {
pattern = "*",
callback = function()
vim.cmd("loadview")
end,
})
```

---

### ⚙️ 如何选择？

| 如果你需要... | 就用 |
| --- | --- |
| 恢复整个项目的窗口布局（多个文件、标签页、分屏） | `:mksession` |
| 每次打开文件时继续上次的编辑位置和折叠状态 | `:mkview` |
| 两者都要 | 可以同时使用，它们保存的信息不重叠 |

---

### 💡 配合 `nvim-ufo` 使用

如果你在用 `nvim-ufo`，`mkview` 是保存折叠状态的关键。确保 `viewoptions` 包含 `folds`：

lua

```lua
vim.opt.viewoptions = { "cursor", "folds", "slash", "unix" }
```

这样，`mkview` 会记录你在 `ufo` 中创建的所有折叠（包括手动和自动的），下次打开文件时恢复。
