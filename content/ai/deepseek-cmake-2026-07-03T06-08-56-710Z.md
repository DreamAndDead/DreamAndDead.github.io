## Assistant

要为 CTest 测试添加标签，核心是使用 `set_tests_properties` 命令为指定测试设置 `LABELS` 属性。这样你就可以在 `ctest` 命令中按标签来筛选和执行测试了。

### 🏷️ 如何在 CMakeLists.txt 中添加标签

在定义测试之后，通过 `set_tests_properties` 来添加标签，语法如下：

cmake

```cmake
add_test(NAME MyTest COMMAND my_test_executable)

set_tests_properties(MyTest PROPERTIES LABELS "unit;quick;math")
```

其中 `"unit;quick;math"` 就是为 `MyTest` 这个测试添加的标签列表，你可以根据需求创建任意文本标签，比如 `integration`、`smoke` 等[-1](https://cmake-doc.readthedocs.io/zh-cn/latest/prop_test/LABELS.html)[-2](https://cmake.org/cmake/help/v3.25/prop_test/LABELS.html)[-7](https://cmake.org/pipermail/cmake/2014-July/057996.html)。

#### 按目录批量添加标签

如果你的项目测试目录结构清晰，可以用 `set_directory_properties` 为某个目录下所有测试统一添加标签，避免逐个添加，这个特性从 CMake 3.10 开始支持[-4](https://cmake.com.cn/cmake/help/latest/prop_dir/LABELS.html#prop_dir:LABELS)[-6](https://cmake-doc.readthedocs.io/zh-cn/latest/prop_dir/LABELS.html)。

cmake

```cmake
# 在包含多个测试的子目录的 CMakeLists.txt 中
set_directory_properties(PROPERTIES LABELS "integration;backend")
```

### 🎯 使用标签筛选测试

设置好标签后，就可以通过 `ctest` 命令的 `-L`（包含）和 `-LE`（排除）选项来运行特定测试了[-1](https://cmake-doc.readthedocs.io/zh-cn/latest/prop_test/LABELS.html)[-2](https://cmake.org/cmake/help/v3.25/prop_test/LABELS.html)[-5](https://browse.dgit.debian.org/cmake.git/tree/Help/prop_test/LABELS.rst?id=0fcbd26aaf0d3b76521778eb1a2f839850b53ee2)。

-
**运行所有包含 `quick` 标签的测试**:
bash

```bash
ctest -L quick
```
-
**运行同时包含 `unit` 和 `quick` 标签的测试**（可以指定多个 `-L`，它们是 AND 关系）[-8](https://archive.softwareheritage.org/browse/snapshot/f6a81224388322bcff614c9cbd16875b25865a96/log/?origin_url=https://github.com/dougshidong/PHiLiP):
bash

```bash
ctest -L unit -L quick
```
-
**运行所有测试，但排除包含 `slow` 标签的测试**:
bash

```bash
ctest -LE slow
```

### 🔗 与 VS Code 集成

如果你在使用 VS Code 的 **CMake Tools** 扩展，也可以在设置中配置测试筛选。

打开 VS Code 设置 \(`Ctrl+,` 或 `Cmd+,`\)，搜索 `cmake.testExplorerFilter`，将其值设为 `-L <你的标签>` 即可。这样在 Test Explorer 中运行测试时，会自动应用该筛选条件。
