mkview

## Assistant

`mkview` 是 Neovim 中一个非常实用但容易被忽略的内置命令。它的核心作用是**保存当前窗口的“视图”**，包括折叠、光标位置、滚动位置、文件编辑状态等信息，并在下次打开文件时恢复。

### 🧠 工作原理

-
当你执行 `:mkview` 时，Neovim 会把当前窗口的状态（包括折叠、光标位置等）保存到一个文件中。
-
默认情况下，这些视图文件会被存放在 `~/.local/state/nvim/view/` 目录下。
-
下次你再打开同一个文件时，Neovim 会自动读取这个视图文件，恢复你上次离开时的状态。

### ⚙️ 基本用法

| 命令 | 作用 |
| --- | --- |
| `:mkview` | 保存当前窗口的视图 |
| `:loadview` | 手动加载视图（通常 Neovim 会自动加载） |
| `:mkview!` | 强制覆盖已存在的视图文件 |
| `:set viewoptions=` | 控制视图保存哪些内容 |

### 🔧 常用配置

在 `init.lua` 中，你可以这样配置 `viewoptions` 来控制保存的内容：

lua

```lua
-- 控制 mkview 保存哪些信息
vim.opt.viewoptions = {
"cursor",   -- 保存光标位置
"folds",    -- 保存折叠
"slash",    -- 使用 Unix 风格路径
"unix",     -- 使用 Unix 换行符
"options",  -- 保存局部选项
"curdir",   -- 保存当前目录
}
```

### 📂 与其他插件的协作

-
**`nvim-ufo`**：`ufo` 基于 `foldmethod=manual` 工作，所以你的手动折叠可以通过 `mkview` 保存。
-
**`nvim-tree`**：文件和目录树的打开状态，通常由它自己的会话管理功能控制，不依赖 `mkview`。

### 💡 自动保存和加载视图

如果你希望 Neovim 在退出时自动保存视图，在打开文件时自动加载，可以设置自动命令：

lua

```lua
-- 自动保存视图
vim.api.nvim_create_autocmd("BufWinLeave", {
pattern = "*",
callback = function()
vim.cmd("mkview")
end,
})

-- 自动加载视图
vim.api.nvim_create_autocmd("BufWinEnter", {
pattern = "*",
callback = function()
vim.cmd("loadview")
end,
})
```

### 🆚 `mkview` vs 会话管理（Session）

| 功能 | `mkview` | 会话管理（`:mksession`） |
| --- | --- | --- |
| **作用范围** | 单个文件/窗口 | 整个 Neovim 会话（所有窗口、标签页） |
| **保存内容** | 折叠、光标、滚动位置 | 布局、插件状态、文件列表 |
| **适合场景** | 日常编码，想保留单个文件的浏览状态 | 复杂项目的整体工作区恢复 |

### 💡 注意事项

-
`mkview` 对大型文件或复杂折叠可能有一定性能开销，但通常可以忽略。
-
如果你在不同的机器上使用同一个配置，确保视图文件的路径一致，否则可能无法加载。可以通过 `set viewdir` 来指定视图文件的存放位置。

如果你想让 `mkview` 和 `nvim-ufo` 的折叠状态完美配合，可以试试将 `viewoptions` 中的 `folds` 选项保留，并配合 `BufWinEnter` 自动加载视图。
