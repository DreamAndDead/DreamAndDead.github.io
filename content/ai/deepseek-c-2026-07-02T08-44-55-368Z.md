## Assistant

在 Visual Studio 中自定义调试时的数据显示，主要有两种方法，分别适用于**托管代码（C\#/[VB.NET](https://VB.NET)）**和**原生C\+\+代码**。

### 🎯 适用于 .NET \(C\#/VB\) 的 `DebuggerDisplay`

这是为 .NET 类型自定义调试信息最简单、最直接的方法。你可以通过一个特性（Attribute）来定义类型在调试器窗口（如“监视”或“局部变量”）中**主要显示的文本内容**。

1.
**基本用法**：在你的类或结构上添加 `[DebuggerDisplay]` 特性，其中的字符串可以使用大括号 `{}` 来引用实例的字段、属性甚至无副作用的方法[-2](https://vslive.com/blogs/news-and-tips/2024/10/debugging-complex-classes-with-the-debuggerdisplay-attribute.aspx)。
2.
**示例**：
csharp

```csharp
[DebuggerDisplay($"Name: {LastName}, {FirstName}")]
public class Person {
public string FirstName { get; set; }
public string LastName { get; set; }
public string PhoneNumber { get; set; }
}
```
**效果**：当你在调试器中查看 `Person` 对象时，`值` 列会直接显示为友好的 `Name: Smith, John`，而不需要展开对象去查找各个属性[-2](https://vslive.com/blogs/news-and-tips/2024/10/debugging-complex-classes-with-the-debuggerdisplay-attribute.aspx)。

> **提示**：你还可以使用 `DebuggerDisplay` 的 `Name` 和 `Type` 命名参数，来控制调试器窗口中 `名称` 和 `类型` 列的显示。

### 🧬 适用于 C\+\+ 的 Natvis 框架

对于 C\+\+ 开发者，调试复杂的数据结构（如自定义容器、链表、树等）时，Visual Studio 默认的显示方式往往不够直观。这时就需要 **Natvis \(Native Visualization\)** 框架。

1.
**核心机制**：Natvis 使用 `.natvis` 后缀的 **XML 文件**来定义可视化规则。通过这些规则，你可以精确控制调试器如何展示特定类型。
2.
**主要用途**：

-
**隐藏内部细节**：只显示对调试有用的关键数据[-1](https://developer.aliyun.com/article/1670231)。
-
**优化集合展示**：让自定义的容器类在调试器中像 `std::vector` 一样，可以清晰地展开并查看其所有元素。
-
**计算并显示派生属性**：显示一些需要计算才能得到的中间状态[-1](https://developer.aliyun.com/article/1670231)。
3.
**使用方法**：

-
在 C\+\+ 项目中，右键点击“添加” -\> “新建项”，选择“**调试器可视化文件 \(.natvis\)**”。
-
编辑生成的 `.natvis` 文件，通过 `<Type>` 标签定义你的类和结构体的显示规则。
-
在调试过程中，可以随时修改 `.natvis` 文件，修改保存后，调试器窗口会自动更新，无需重启调试会话。

> **注意**：Natvis 只适用于类（class）和结构体（struct），不能用于 `typedef` 。
