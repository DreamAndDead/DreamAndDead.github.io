## Assistant

要把交换行的功能绑定到快捷键，可以这样做：

### ⌨️ 常用快捷键绑定

在 `init.lua` 中添加以下映射，让操作更顺手：

lua

```lua
-- 交换当前行和下一行
vim.keymap.set("n", "<A-j>", "ddp", { desc = "Swap line down" })

-- 交换当前行和上一行
vim.keymap.set("n", "<A-k>", "ddkP", { desc = "Swap line up" })
```

-
按住 `Alt` 键的同时按 `j` 键：将当前行下移一行。
-
按住 `Alt` 键的同时按 `k` 键：将当前行上移一行。

### 💡 如果你想在可视模式下交换选中的行

如果你习惯用可视模式选中多行后整体移动，可以这样配置：

lua

```lua
-- 可视模式下，将选中的行下移
vim.keymap.set("v", "<A-j>", ":move '>+1<CR>gv-gv", { desc = "Move selection down" })

-- 可视模式下，将选中的行上移
vim.keymap.set("v", "<A-k>", ":move '<-2<CR>gv-gv", { desc = "Move selection up" })
```

这里的 `:move` 命令是 Vim 原生的，可以高效地移动整行或选中的行块。

### 🧩 使用 `vim-exchange` 插件的快捷键

如果你安装了 `vim-exchange` 插件，可以这样配置快捷键：

lua

```lua
-- 可视模式下，用 cx 标记交换区域
vim.keymap.set("x", "cx", "<Plug>(exchange)", { desc = "Exchange selection" })
```

然后：

1.
在可视模式下选中第一块文本，按 `cx`。
2.
移动到第二块文本，再用可视模式选中，按 `cx` 交换。

### 📋 总结

| 场景 | 快捷键 | 说明 |
| --- | --- | --- |
| 交换当前行与下一行 | `<A-j>` | 将当前行向下移动一行 |
| 交换当前行与上一行 | `<A-k>` | 将当前行向上移动一行 |
| 交换选中的区域 | `cx` | 需要 `vim-exchange` 插件支持 |

如果你用 LazyVim，可以把这个配置放到 `~/.config/nvim/lua/plugins/keymaps.lua` 或 `~/.config/nvim/lua/config/keymaps.lua` 中，让快捷键全局生效。
