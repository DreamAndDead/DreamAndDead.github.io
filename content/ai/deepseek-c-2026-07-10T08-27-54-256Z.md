## 为什么二维向量没有叉乘？

更准确的说法是：**二维向量没有“向量积”（Vector Product）**，但二维向量的“叉乘”是一个**标量**，而不是向量。这是由叉乘的数学定义决定的。

---

### 1. **叉乘的定义**

叉乘（Cross Product）在三维空间中定义为：

$$
\mathbf{a} \times \mathbf{b} =
\begin{vmatrix}
\mathbf{i} & \mathbf{j} & \mathbf{k} \\
a_x & a_y & a_z \\
b_x & b_y & b_z
\end{vmatrix}
= (a_y b_z - a_z b_y)\mathbf{i} + (a_z b_x - a_x b_z)\mathbf{j} + (a_x b_y - a_y b_x)\mathbf{k}
$$

**关键点：** 叉乘的**结果是一个向量**，且这个向量**垂直于原来的两个向量**。

---

### 2. **为什么二维向量没有向量叉乘？**

**因为二维空间中没有“垂直于两个向量的第三个方向”。**

在二维平面中，两个向量 $\mathbf{a} = (a_x, a_y)$ 和 $\mathbf{b} = (b_x, b_y)$ 只能确定一个平面。如果计算：

$$
\mathbf{a} \times \mathbf{b} = (a_x b_y - a_y b_x) \mathbf{k}
$$

结果指向的是 **垂直于二维平面的方向（z 轴）**，超出了二维空间。

所以：

-
在**二维向量**中，叉乘不是一个向量，而是一个标量
-
这个标量实际上就是三维叉乘的 **z 分量**：$a_x b_y - a_y b_x$

---

### 3. **二维向量的“叉乘”是什么？**

二维向量的“叉乘”通常指**有符号面积**（Signed Area）或**行列式值**：

$$
\text{cross2D}(\mathbf{a}, \mathbf{b}) = a_x b_y - a_y b_x
$$

**这个标量的意义：**

-
**大小**：等于由 $\mathbf{a}$ 和 $\mathbf{b}$ 组成的平行四边形的面积
-
**符号**：表示旋转方向（正 = 逆时针，负 = 顺时针）

cpp

```cpp
struct Vector2 {
double x, y;

// 二维叉乘（返回标量）
double cross(const Vector2& other) const {
return x * other.y - y * other.x;
}
};

int main() {
Vector2 a(1, 0);
Vector2 b(0, 1);

double area = a.cross(b);  // 1*1 - 0*0 = 1
// 面积 = 1，方向为逆时针
}
```

### 4. **二维叉乘的实际应用**

#### 4.1 判断旋转方向

```cpp
Vector2 a(1, 0);
Vector2 b(0, 1);
double cross = a.cross(b);  // 1 > 0 → 从 a 到 b 是逆时针旋转
```

```cpp
// 判断点 p 在直线 ab 的哪一侧
Vector2 a(0, 0), b(1, 0), p(0.5, 1);

double side = ab.cross(ap);  // 1*1 - 0*0.5 = 1 → 左侧
```

```cpp
std::vector<Vector2> polygon = {{0,0}, {1,0}, {1,1}, {0,1}};
double area = 0;
for (size_t i = 0; i < polygon.size(); ++i) {
size_t j = (i + 1) % polygon.size();
```

#### 4.4 判断两条线段是否相交

cpp

```cpp
bool segmentsIntersect(Vector2 a, Vector2 b, Vector2 c, Vector2 d) {
Vector2 ab = b - a;
Vector2 ac = c - a;
Vector2 ad = d - a;

double cross1 = ab.cross(ac);  // 方向1
double cross2 = ab.cross(ad);  // 方向2

// c 和 d 在 ab 的两侧
if (cross1 * cross2 > 0) return false;

Vector2 cd = d - c;
Vector2 ca = a - c;
Vector2 cb = b - c;

double cross3 = cd.cross(ca);
double cross4 = cd.cross(cb);

return cross3 * cross4 <= 0;  // a 和 b 在 cd 的两侧或端点
}
```

### 5. **三维叉乘 vs 二维叉乘**

| 特性 | 三维叉乘 | 二维叉乘 |
| --- | --- | --- |
| **输入** | 两个三维向量 | 两个二维向量 |
| **输出** | 一个三维向量（垂直于输入） | 一个标量（有符号面积） |
| **几何意义** | 法向量 | 面积 \+ 旋转方向 |
| **维度** | 结果在三维空间 | 结果在二维平面外（z 轴） |
| **公式** | $(a_y b_z - a_z b_y, a_z b_x - a_x b_z, a_x b_y - a_y b_x)$ | $a_x b_y - a_y b_x$ |

### 6. **C\+\+ 中的实现**

cpp

```cpp
#include <iostream>
#include <cmath>

struct Vector2 {
double x, y;

Vector2(double x = 0, double y = 0) : x(x), y(y) {}

// 二维叉乘（标量）
double cross(const Vector2& other) const {
return x * other.y - y * other.x;
}

// 点乘
double dot(const Vector2& other) const {
return x * other.x + y * other.y;
}

// 模长
double length() const {
return std::sqrt(x*x + y*y);
}
};

int main() {
Vector2 a(1, 0);
Vector2 b(0, 1);
Vector2 c(1, 1);

std::cout << "a × b = " << a.cross(b) << "\n";   // 1
std::cout << "a × c = " << a.cross(c) << "\n";   // 1*1 - 0*1 = 1
std::cout << "b × a = " << b.cross(a) << "\n";   // 0*0 - 1*1 = -1
std::cout << "b × c = " << b.cross(c) << "\n";   // 0*1 - 1*1 = -1

// 面积计算
double area = std::abs(a.cross(b)) / 2.0;  // 三角形面积
std::cout << "三角形面积 = " << area << "\n";

return 0;
}
```

```text

a × c = 1
b × a = -1
b × c = -1
三角形面积 = 0.5
```

### 7. **总结**

1.
**数学上**：叉乘（向量积）在三维空间中有意义，结果是一个向量。二维空间中没有对应的向量结果。
2.
**实用上**：二维向量的"叉乘"被定义为标量 $a_x b_y - a_y b_x$，用于表示有符号面积和旋转方向。
3.
**命名建议**：在代码中，对于二维向量的 `cross` 方法，最好在文档中说明它返回的是标量（有符号面积），以区别于三维叉乘。

### 核心记忆

> **三维叉乘 = 向量（垂直于平面）**
> **二维叉乘 = 标量（有符号面积）**
> **二维叉乘是三维叉乘的 z 分量**
> **符号表示方向，大小表示面积**
