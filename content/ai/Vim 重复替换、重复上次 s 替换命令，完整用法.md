# Vim 重复替换、重复上次 s 替换命令，完整用法

## 1. 最简单：重复上次替换命令 【`&`】

执行一次替换后，光标放在目标行，按 **`&`**，原地重复执行**上一次的 `:s` 行内替换**。

```vim
:s/old/new/      当前行第一次替换
&               再次执行 :s/old/new/
```

### 加标志位重复

`g&` = 重复上次替换，并且带上全局 `g` 标志（整行所有匹配）。

## 2. 全局范围重复上次替换 【`g&&`】

对**整个文件所有行**，完整重复上一条 `:s` 命令。

## 3. 跨区域重复：配合范围 + &

```vim
10,20&   在10~20行，重复上次行替换
%&       全文重复上次:s
```

## 4. 重复**完整 Ex 命令（含全局替换 :% s）**：`@:`

- `:` 会把最近一条 Ex 命令存入寄存器 `:`
- 按 `@:` 即可重复执行整条命令（包括 `:%s`、`:g` 等）

```vim
:%s/foo/bar/gc
@:   完整重新执行一次全局替换
```

## 5. 模式替换 + 确认 (c)，重复操作

带确认 `c` 选项：`:%s/a/b/gc`
 弹窗选项：
`y` 替换当前，`n` 跳过，`a` 全部替换，`q` 退出。
 中途退出后，后续行想继续，依然可以用 `&` 单行重复。

## 6. 常用快捷键绑定（顺手方案）

```lua
vim.keymap.set("n", "<F7>", "&", {desc = "重复上次行替换"})
vim.keymap.set("n", "<F8>", "g&&", {desc = "全文重复上次替换"})
vim.keymap.set("n", "<F9>", "@:", {desc = "重复上一条Ex命令"})
```

## 7. 容易踩坑细节

1. `&` **只重复 `:s` 行替换**，不会重复 `:%s` 全局命令，全局命令必须用 `@:`
2. `&` 会沿用上次的 flag (g/c/i)，不需要重写参数
3. 想要**修改替换规则再重复**： 按 `q:` 打开命令历史窗口，编辑旧的 `s` 命令回车执行。

## 速记总结

1. 单行重复上次行替换：`&`
2. 全文重复上次行替换：`g&&`
3. 重复完整全局 `:%s` 等整条命令：`@:`
