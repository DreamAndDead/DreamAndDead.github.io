## User

独占全屏和无边框全屏的区别是什么

## Assistant

SDL3 里的这两种全屏模式，核心区别在于：**独占全屏会改变显示器的分辨率，而“无边框全屏桌面模式”不会，它只是创建一个没有边框、铺满屏幕的窗口[-4](https://github.com/libsdl-org/sdlwiki/blob/125438ac980070c250369561cb247ad0a4b70d87/SDL3/SDL_SetWindowFullscreenMode.md)[-12](https://wiki.libsdl.org/SDL3/SDL_SetWindowFullscreenMode)。**

两者最关键的差异如下：

| 特性 | 独占全屏 | 无边框全屏桌面模式 \(默认\) |
| --- | --- | --- |
| **工作方式** | 程序直接接管显示输出，会改变显示器的分辨率和刷新率[-4](https://github.com/libsdl-org/sdlwiki/blob/125438ac980070c250369561cb247ad0a4b70d87/SDL3/SDL_SetWindowFullscreenMode.md)[-12](https://wiki.libsdl.org/SDL3/SDL_SetWindowFullscreenMode)。 | 程序创建一个覆盖整个屏幕的“无边框窗口”，使用桌面当前的分辨率和刷新率[-2](https://wiki.libsdl.org/SDL3/SDL_SetWindowFullscreen/raw)[-5](https://wiki.libsdl.org/SDL3/SDL_SetWindowFullscreen)。 |
| **性能** | **理论性能最高**。系统资源会优先分配给游戏，这是此模式的唯一优势。 | 性能受桌面窗口管理器（DWM）影响，可能存在轻微额外延迟。 |
| **切换速度** | **切换较慢**。切换时会伴随短暂的黑屏或屏幕闪烁，因为显示器需要改变模式[-1](https://github.com/libsdl-org/SDL/issues/12791)[-7](https://stackoverflow.com/questions/79614593/forcing-non-exclusive-borderless-fullscreen-with-sdl3-opengl-on-windows-11)。 | **切换极快，几乎没有感知**。只是窗口状态变化，不涉及底层显示模式切换[-1](https://github.com/libsdl-org/SDL/issues/12791)[-7](https://stackoverflow.com/questions/79614593/forcing-non-exclusive-borderless-fullscreen-with-sdl3-opengl-on-windows-11)。 |
| **多任务与兼容性** | 兼容性差。**Alt\+Tab 切出时可能卡顿或黑屏**，系统通知/Overlay（如音量条）也无法显示在游戏上层[-1](https://github.com/libsdl-org/SDL/issues/12791)[-7](https://stackoverflow.com/questions/79614593/forcing-non-exclusive-borderless-fullscreen-with-sdl3-opengl-on-windows-11)。 | 兼容性好。**Alt\+Tab 切换流畅**，系统Overlay可以正常显示在游戏上层[-1](https://github.com/libsdl-org/SDL/issues/12791)[-7](https://stackoverflow.com/questions/79614593/forcing-non-exclusive-borderless-fullscreen-with-sdl3-opengl-on-windows-11)。 |

### 💻 在 SDL3 中如何控制

在 SDL3 中，这两种模式的切换由 `SDL_SetWindowFullscreenMode` 函数控制：

c

```c
// 设置为无边框全屏桌面模式 (这是调用 SDL_SetWindowFullscreen(true) 时的默认行为)
SDL_SetWindowFullscreenMode(window, NULL);

// 设置为独占全屏模式，mode 需要从 SDL_GetFullscreenDisplayModes() 中获取
SDL_SetWindowFullscreenMode(window, &some_display_mode);
```

需要注意，设置后需要通过 `SDL_SetWindowFullscreen(window, true)` 来实际应用[-12](https://wiki.libsdl.org/SDL3/SDL_SetWindowFullscreenMode)[-5](https://wiki.libsdl.org/SDL3/SDL_SetWindowFullscreen)。

### ⚠️ 一个潜在问题

使用 OpenGL 时，在 Windows 上即使你试图创建一个无边框窗口，在调用 `SDL_GL_SwapWindow` 后，驱动可能为了性能会**强制切换成独占全屏模式**，并伴随黑屏和 Alt\+Tab 卡顿[-1](https://github.com/libsdl-org/SDL/issues/12791)[-7](https://stackoverflow.com/questions/79614593/forcing-non-exclusive-borderless-fullscreen-with-sdl3-opengl-on-windows-11)。SDL 官方对此的回应是，这是 OpenGL 驱动的“有意行为”[-7](https://stackoverflow.com/questions/79614593/forcing-non-exclusive-borderless-fullscreen-with-sdl3-opengl-on-windows-11)。

### 💎 总结与选择建议

-
**推荐选择**：对于绝大多数现代游戏和应用程序，**无边框全屏桌面模式是首选**。它提供了几乎一样的体验，但切换窗口、查看通知都方便得多，特别是如果你希望程序能配合你之前提到的“窗口位置记忆”功能时，这个模式也更友好。
-
**何时使用独占**：只有在**性能是最优先考虑**，且能接受黑屏和切换不便时，才考虑使用。
