# 国内算法竞赛完整分类（按人群：中学生信奥、大学生主流、企业厂赛、日常线上赛）

## 一、中学生官方信奥体系（CCF 主办，升学含金量最高，五大学科奥赛）

整套晋升路线：**CSP-J/S → NOIP → NOI → 国家集训队 → IOI 国际赛**

1. **CSP-J/S（非专业级软件能力认证）**
   - J 组（普及组）：小学高年级、初中入门；S 组（提高组）：初高中进阶，**S 组一等奖是 NOIP 入场券**
   - 赛制：OI 赛制（赛后出分，按测试点得分），每年 10 月考试，CCF 官方唯一入门认证。
2. **NOIP 全国青少年信息学奥林匹克联赛** 面向初高中省市级选拔，省一为强基计划、综合评价升学核心加分，每年 11 月开赛。
3. **NOI 全国信息学奥林匹克决赛** 各省省队顶尖选手参赛，国内中学生算法天花板；**金牌可保送清北，银牌可直通顶尖高校强基面试**，每年 7 月举办。

## 二、大学生主流算法竞赛（保研、校招求职核心加分）

### 1. 顶尖硬核竞技（ACM 体系，难度最高）

#### CCPC 中国大学生程序设计竞赛（国内 ACM 正统）

国内最高规格大学生团队算法赛，**3 人一队共用一台电脑，5 小时解题，ACM 实时罚时排名**，对标国际 ICPC 亚洲区域赛，晋级全球总决赛。
 适合目标大厂算法岗、顶尖保研，圈内认可度第一，企业算法招聘高度看重。

#### ICPC 亚洲区域赛

国际 ACM 体系亚洲赛区，CCPC 与 ICPC 互通名额，国内各城市每年多场分站赛，顶尖高校强队同台竞技。

### 2. 大众入门首选：蓝桥杯（全国软件和信息技术专业人才大赛）

- 个人 OI 赛制，每年 3 月省赛、6 月国赛，分本科 A/B/C 组、研究生组，**C++/Python/Java 全支持**，参赛人数国内第一。
- 特点：难度梯度友好，基础题占比高，新手极易上手，获奖难度适中，是计算机新生练手、简历入门奖项首选，国一在双非保研、企业校招认可度很高。

### 3. 教育部高校官方赛事

**GPLT 团体程序设计天梯赛**
 教育部主办，10 人一队、个人做题团队计分，分基础 / 进阶 / 登顶三级题目，侧重考察高校整体编程教学实力，奖项校内评优认可度高，题目偏基础扎实，适合全员练基础算法。

### 4. CCF 官方大学生赛事

**CCSP CCF 大学生计算机系统与程序设计竞赛**
 CCF 主办，不只考纯算法，兼顾系统底层、工程编程能力，题目综合性极强，含金量硬核，适合计算机科班深耕底层与算法。

## 三、互联网大厂厂办算法大赛（求职直通大厂，奖金丰厚）

1. **百度之星程序设计大赛** 国内老牌厂赛，面向全学段（小学至研究生），决赛分大学组、高中组，出题贴合互联网工程算法，获奖选手可直通百度面试，被誉为互联网程序员 “黄埔军校”。
2. **字节青训营编程大赛、阿里天池程序设计赛道、腾讯高校算法竞赛** 大厂自研命题，题型贴近企业业务算法，决赛优秀者直接发放实习 / 校招绿色通道，是进入一线互联网的绝佳跳板。

## 四、日常线上常态化刷题比赛（随时练手感，适配面试）

1. **洛谷月赛、Codeforces 国内场次、AtCoder 国内同步赛** 国内最大 OI/ACM 题库平台，每周 / 每月固定线上赛，完美对标正式竞赛难度，是备赛日常刷题主战场。
2. **LeetCode 周赛 / 双周赛** 周日固定开赛，题目偏向面试算法风格，难度贴合大厂笔试，适合求职面试针对性训练。
3. **PAT 甲级 / 乙级（浙大 PTA 平台）** 天梯赛同裁判系统，乙级入门、甲级进阶，国内很多高校考研机试、企业笔试直接采用 PAT 原题。

## 五、简单选型建议

1. **中学生冲升学、保送**：主攻 **CSP-J/S → NOI**，必学 C++。
2. **大学生新手入门、拿奖项**：首选**蓝桥杯**，可先用 Python 入门，高分必须 C++。
3. **冲顶尖算法能力、备战大厂算法岗**：主攻 **CCPC/ICPC**。
4. **目标互联网校招**：额外参加**百度之星、字节、阿里厂赛**。
5. **日常刷题备赛**：洛谷、Codeforces、LeetCode 周赛。
