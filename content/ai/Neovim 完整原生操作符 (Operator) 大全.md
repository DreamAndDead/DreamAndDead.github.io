# Neovim 完整原生操作符 (Operator) 大全

操作符格式：`[数字]操作符 + motion/文本对象`，**原生一共 15 组标准操作符**，附带作用、用法、双倍行模式，同时附带查看方式、自定义操作符入口 `g@`。
 完整来自官方文档 `:help operator`、`:help motion.txt`Neovim。

## 二、内置命令查看操作符帮助

1. 官方完整文档

```vim
:help operator    # 操作符总览
:help motion.txt  # 操作符+motion完整规则
:help operatorfunc # g@自定义操作符原理
```

2. 可视模式可用操作符列表

```vim
:help visual-operators
```

## 三、如何在 Neovim 动态查看当前可用映射的操作符

### 1. 查看操作符等待模式映射（onoremap，自定义文本对象）

```vim
:omap          # 列出所有 operator-pending 映射（o模式）
:verbose omap  # 附带映射定义文件、行号
```

### 2. 查看可视模式绑定的操作快捷键（x 模式）

```vim
:xmap
:verbose xmap
```

### 3. 查看全局普通模式按键（包含插件自定义操作符，如 gc 注释）

```vim
:nmap
```

## 四、插件扩展的第三方常用操作符（社区标配）

原生只有上面 15 个，主流插件会新增业务操作符，本质是映射封装：

1. **Comment.nvim**`gc{motion}` 注释 / 取消注释，`gcc` 行注释，最常用第三方操作符。
2. **mini.surround / nvim-surround**`ys` 包裹符号、`cs` 替换符号、`ds` 删除符号，包围操作符。
3. **yop.nvim** 用于快速注册你自己写的 Lua 自定义操作符。

## 五、核心规则补充（操作符通用特性）

1. **双倍 = 作用整行** 所有单字符操作符，连续按两次，默认作用**当前整行**：`dd / cc / yy / >> / << / ==`。
2. **数字计数相乘**`2d3w` = 2 × 3 = 删除 6 个单词，操作符数字 + motion 数字相乘。
3. `g@` 万能自定义入口 你之前写自定义操作符，都是依靠 `g@` 配合 `operatorfunc`，它是原生预留的扩展接口，不属于业务操作符，是开发专用。

## 六、区分容易混淆的概念

1. **操作符 Operator**：动作（删 / 改 / 复制 / 缩进），必须搭配范围。
2. **Motion / 文本对象 Text Object**：选区范围（w/i (/ap 等）。 公式：`count + Operator + Motion` 构成完整编辑命令。
